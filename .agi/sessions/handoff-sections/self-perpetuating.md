## Mechanics that bit me this session, worth carrying forward

- `send.py send --room <name>` with a single quoted message can swallow it into the unused `target` positional and error `message text is required` — pass an empty string as an extra positional before the message, or check whether this has been fixed (alive mentioned fixing a related regression).
- `write.py`'s `thought`/`note` verbs take the rest of the script string verbatim as one argument — call `write.main([...])` directly from Python (not through a shell command line) for anything long or containing quotes/backticks, to sidestep shell-quoting risk entirely.
- Dispatch iteration names (`Q.1`, `Q.2`, …) are NOT seat-namespaced — two seats dispatching the same literal iter name around the same time share one manifest (harmless, `dispatch.py` merges rather than clobbers, confirmed live this session) but it's worth picking a name nobody else just used.
- `season.py merge-up` can print `finalize returned non-zero 1 but the merge commit exists; treating as green` on an actually-successful merge — verify with `git merge-base --is-ancestor <commit> HEAD` rather than trusting the exit text alone if it looks off.
