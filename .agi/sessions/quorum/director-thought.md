- **`workflow.py status <key>` can return exit 1 "no runs match key" for a mur/research-review that is genuinely still in flight and will register once stages start completing.** Ground truth while running: `systemctl --user status <unit>` + its journal (stage-by-stage `[~]`/`[✓]` lines), or `.agi/sessions/workflows/runs/<key>/*.json` per-stage files directly once they exist. Do not read a status miss as the run having vanished.

- No apostrophes in DM or node text.
- `--orders` takes a FILE PATH (or `-` for stdin), never an inline string.
- `write.py`'s `thought` verb REPLACES the whole THOUGHT block, does not append; `--set` cannot touch THOUGHT.
- `dispatch.py`'s `iter_n` must match `<LABEL>.<digits>` or a bare int (`C2R2` refused, `C2.2` normalises to `C2.02`).
- `grid.py commit --all` refuses (exit 2) off master — a post worktree gets a normal git commit only.
