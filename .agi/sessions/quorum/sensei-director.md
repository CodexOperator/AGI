## §4 TRAPS (live ones only; fixed-in-code traps deleted)
- 🔴 **NEW (this session): `git add -A -- <path1> <path2>` where ONE pathspec no longer exists (e.g. the pre-move path of a `git mv`) fails the WHOLE command with a `fatal: pathspec ... did not match any files` — and if that line isn't the last one in a multi-line Bash call (no `&&` chaining), the SUBSEQUENT commands in the same call still run, including a `git commit`, which then silently commits only whatever was ALREADY staged (e.g. a bare rename from an earlier `git mv`) while dropping any later unstaged edit to that same file (e.g. a `write.py set` field change made after the move).** The commit succeeds and LOOKS fine — the only tell is `git diff` on the file still showing the intended change as unstaged, or the commit's own `insertions(+)` count reading suspiciously low (here: 0/0 for a rename that should also have carried a field edit).
