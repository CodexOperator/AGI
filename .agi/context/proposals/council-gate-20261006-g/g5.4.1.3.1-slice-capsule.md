## 1. Capsule shape (vs encrypted capsule)

Encrypted capsule (`refs/capsule/C`, §O): tip tree holds `.agi/capsule/C/{cred,k,ring/*}`; pop requires k-of-n signatures; only path ciphertext→plaintext is a combined WHERE decision.

**Slice capsule (`refs/slice/N`)** — same *move-safe tip+CAS* shape, **no seal**:

```
refs/slice/<name>  →  commit C
  tree:
    manifest          # text: one mint_id per line (+ optional path=… tip=…)
    nodes/<mint_id>   # blob = exact node file bytes (same SHA as grid tip blob when equal)
    nested/<child>    # optional: gitlink (mode 160000) → child refs/slice/<child> tip
  parents: prior slice tip (CAS chain) OR none on first pack
  message: "slice <name> pack <selector> @ <trunk-short>"
```

| property | encrypted capsule | slice capsule |
|---|---|---|
| seal/cred/ring/k | yes | **no** |
| tip CAS / replay-lose | yes (`update-ref` old→new) | **yes** (same) |
| move-safe (push/fetch ref) | yes | **yes** |
| view without pop | forbidden (ciphertext) | **allowed** (`git cat-file` / `slice show`) |
| who may move | k-of-n holders | post with write rights on destination ref (matrix / owner of branch or grid trunk) |

**Alive lens:** every limit named — no implied encryption later; encryption stays a separate leaf under g7.16.1.11 if owner re-opens.

## 2. Slice select (argv / discovery)

```
slice pack <name> --root <goal-id>          # walk frontmatter parents:[] BFS/DFS from root; connected subgraph
slice pack <name> --mint <id> [<id>…]       # explicit mint_id list (durable link; never id-alone)
slice pack <name> --range <A>..<B>          # nodes whose blob changed in tip range (git log -G / diff-tree paths under .agi/nodes/)
slice pack <name> --path <glob>…            # pathspec under .agi/nodes/ (escape hatch; prefer --root/--mint)
```

Discovery rules (no hand-editing refs):
- Resolve node files via `git ls-tree -r ${AGI_TRUNK}` + frontmatter `mint_id:` / `id:` / `parents:` (stdlib-regex like grid.py — or `git grep` + `jq` if yaml already on PATH).
- Refuse empty selection; refuse mint_id not present on trunk; print selected count + names before write.
- Nested: `--root` may include child goals that themselves have prior `refs/slice/*` → record as `nested/` gitlinks (compose).

## 3. Move verbs (branch ↔ grid; recursive)

| verb | action |
|---|---|
| `pack` | build tree → `commit-tree` → `git update-ref refs/slice/N NEW [OLD]` (CAS) |
| `show` | print manifest + tip + nested; `git cat-file` only |
| `ls` | `for-each-ref refs/slice/` |
| `unpack` | materialize `nodes/*` into a throwaway wt or stdout tarball — **does not** rewrite live branch by default |
| `move --to-grid` | for each mint in manifest: `git update-ref refs/grid/$TRUNK/node/$MINT <blob-commit>` (grid commit-tree shape per grid.py) from slice tip; CAS per node |
| `move --from-grid` | inverse: gather grid tip blobs for mint list → pack new slice tip |
| `move --to-branch <ref>` | `git merge-tree` / sparse commit onto `<ref>` carrying only slice paths (or ff update of a dedicated loop branch) |
| `move --from-branch <ref>` | select paths from branch tip → pack |
| `push` / `fetch` | thin wrappers: `git push REMOTE refs/slice/N:refs/slice/N` (and optional `refs/grid/...` subset) |

**Recursive/unified:** a slice tip with `nested/` gitlinks moves children first (depth-first), then self — one argv `slice move --to-grid N` walks the tree. Nested compose = unified mechanism for town/node-as-branch rollup.

**All-is-one lens:** one primitive (`slice`) for pack+move; grid remains D2 history; slice is the *portable bag*; no second Python mover beside grid.py.
