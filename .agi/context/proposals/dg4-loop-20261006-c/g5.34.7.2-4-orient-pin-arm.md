## g5.34.7.2 — `### orient` (engine-post) + `### agi-rc` rcfile + one arm
- `orient` is the **driver connect verb** for all raw-shell panes including DG/DT. The driver types `orient` on attach. It emits `\033c`, then the header `orient <p> rev=<short> dump_sha256=<64hex> pin=<rotate_pct|-> card=<short>`, then `===== startup <p> =====`, then the dump. The agent reads `o` from the latest `^orient ` line. 0 B to i; o is never truncated by orient.
- Dump = **committed seed blobs only**. agi-sync now does `git show HEAD:<seed>`, and its `git diff --stat` line is dropped (R1/R2; this also applies to the grok-bot rules file, by design).
- Shell start: agi-run exports `AGI_ORIENTED=1`, runs `orient`, then `mail-wake watch&`, then `exec bash --rcfile ~/bin/agi-rc -i`. agi-rc orients only if the latch is unset and sources mail-wake. No passive-viewer latch.
- Evidence: as DG4 into a file, rc 0, header `pin=-` (DG excluded), same `dump_sha256` on re-run, 3 seed sections.

## g5.34.7.3 — `### pin` (Path A, awk; no `$((`)
- The driver writes `~/meter` = `<0..1> <epoch>` each turn (1.0 after summarization). `pin` applies only to rows **with a `grokbot` cell**, so DG/DT never get a pin.
- Refusals: missing, non-numeric, >1 or stale (>6h) → `[refused] meter`, rc 2 (printed once per refusal run).
- `≥ rotate_pct/100` → `card-prompt <p> meter=<f> rev=<sha>` plus the KEEP text, **once per crossing**. The watcher loop forwards it to o and the W1 wake.
- `pin rotate` is the kill gate. It refuses when the card blob is unchanged since the prompt; otherwise `touch ~/.fresh; kill $PPID` (unit already `Restart=always`).
- posts cells: `engine.rotate_pct 47→33` on belam, sanctuary-master, plan-master, alive, all-is-one, self-perpetuating. **thought-master is left at 47.** Its grokbot only binds via g5.34.3.1 on this same branch, so SM decides whether TM gets 33 at land.
- Evidence (fixture): 0.32 → none; 0.34 → prompt once (the second call is silent); stale → refused; rotate with unchanged card → refused; changed card → `.fresh` set and parent killed; DG row → no-op.
- KEEP-text note: the prompt says `then run: pin rotate (= touch ~/.fresh;kill $PPID, gated on the card blob)`, because the raw kill would bypass the gate.
