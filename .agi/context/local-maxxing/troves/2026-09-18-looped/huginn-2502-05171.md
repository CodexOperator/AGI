## PAGE 1 — arXiv abs/html (fetched 2026-09-18)
URL: https://arxiv.org/abs/2502.05171 ; https://arxiv.org/html/2502.05171v2
- TITLE (MEASURED): "Scaling up Test-Time Compute with Latent Reasoning: A Recurrent Depth Approach"
- AUTHORS (MEASURED): Jonas Geiping, Sean McLeish, Neel Jain, John Kirchenbauer, Siddharth Singh,
  Brian R. Bartoldson, Bhavya Kailkhura, Abhinav Bhatele, Tom Goldstein.
- DATE (MEASURED): submitted 2025-02-07.
- MECHANISM (2 lines, MEASURED): prelude (2 layers) -> a weight-tied recurrent block (4 layers)
  iterated `num_steps` times -> coda (2 layers); the model unrolls to arbitrary depth at test time
  by iterating the recurrent block, reasoning in latent space instead of emitting tokens.
- DIFFERENCE FROM TEMPORAL RECURRENCE: this is DEPTH recurrence — the SAME position is refined by
  re-applying the block; state does not cross token boundaries beyond ordinary KV attention.

## CPU RUNNABILITY (MEASURED / ESTIMATE)
- No GGUF for this model. HF GGUF search "huginn" returns only unrelated Llama-2 "Huginn-13B" quants
  (base model `The-Face-Of-Goonery/...`), NOT tomg-group-umd/huginn-0125 (MEASURED).
- llama.cpp has an open feature request for recurrent/thinking support (issue #12486, MEASURED);
  no `huginn` arch in llama.cpp master today (MEASURED grep of src/llama-arch.h).
- CPU path = transformers `trust_remote_code=True` + torch; must downcast F32 -> bf16 (7.8 GB
  ESTIMATE) or quantise to fit the ~7 GB free RAM comfortably.
- ESTIMATE tok/s on the 4-core aarch64 box, weights streamed once per loop, BW 12-24 GB/s:
  r=8: 0.19-0.38 tok/s; r=32: 0.048-0.096 tok/s (10-21 s/token). NOT kid-tier at useful depth.

## TRAINING RECIPE COST (MEASURED)
- Final model: 800B tokens (795B scheduled); non-recurrent baseline: 180B tokens on 256 nodes.
- Hardware: an academic AMD-accelerator cluster (generic class). bfloat16 mixed precision.
- Compute framing (MEASURED): ~3.5B params but "raw FLOPs close to what a 32B parameter transformer
  would consume during pretraining"; test-time scaling "up to FLOP budgets equivalent to a standard
  50B parameter fixed-depth transformer". Learning rate never cooled from peak (caveat in paper).

## VERDICT FOR THE TOWN
- Best-quality released recurrent-depth model, Apache-2.0, with a clean same-param loop-vs-no-loop
  proof. But 15.63 GB F32 + no GGUF + 132 effective depth = NOT runnable at kid tier on the box.
  Keep as the archival upper reference; run it only if a bf16/Q4 GGUF and a llama.cpp arch appear.
