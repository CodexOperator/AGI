- MECHANISM (one paragraph, MEASURED from PDF): Each transformer layer carries TWO weight sets.
  AR weights theta_AR trained by standard NTP (quality); diffusion weights theta_Delta = rank-128
  LoRA adapters (alpha=256) on every AR weight matrix, trained by "Diffusion Distillation" with
  theta_AR FROZEN. Diffusion pathway drafts a block of tokens in parallel; AR weights alone verify
  by rejection sampling (speculative-decoding math, Leviathan Cor. 3.6), so the AR output
  distribution is PROVABLY preserved -> lossless. No separate draft model. Samplers = "Psi-Spec":
  Linear (system throughput) and Tree (per-request). Uniform-state discrete diffusion (pi = 1/K,
  self-correcting), not masked. Works on any causal AR net incl. SSMs.
- HEADLINE NUMBERS (MEASURED, Table 1 / Sec 5):
  * up to 3x speedup over base AR; 2x at the LARGEST batch size the base AR fits (batch 64 -> 1.5x;
    batch 1 -> ~2.2x).
  * System throughput 5255 tok/s vs Mercury 2 1197 (~4.6x higher) on "slower" H200 vs Blackwell.
  * 8B Uno > 26B DiffusionGemma and proprietary Mercury 2 on all agentic/coding/long-context.
    e.g. tau2-Telecom 90.1 vs 68.1 vs 71; SWE-bench Verified 68.4 vs 18.7; AA-LCR 68.0 vs 19.7.
  * Avg TPF 1.9 (Linear B4) / 2.7 (Tree) vs DiffusionGemma 17.56 / Nemotron 5.41.
  * RL: up to 40% end-to-end training speedup; adapters survive RL with nominal 6% TPF drop.
- HARDWARE (MEASURED): trained/evaluated on H200 nodes (8 GPUs each). Uno from-scratch: 60 h on
  8 nodes x 8 H200. UnoQwen diffusion-weights only: ~32 h on 4 nodes x 8 H200. Baselines measured
  at bf16. Needs FlashAttention-2 (linear) and FA3 (tree) — i.e. Hopper+ for the fast path.

- COMPARISON — Cache-to-Cache (arXiv 2510.03215, "Cache-to-Cache: Direct Semantic Communication
  Between Large Language Models", read 2026-09-18): MEASURED abstract. Both keep LLMs FROZEN and
  learn a projector/fuser that maps SOURCE model's KV-cache into TARGET model's KV-cache, plus a
  learnable GATE selecting which target layers receive cache. Claims 6.4-14.2% avg accuracy over
  individual models, ~3.1-5.4% over text communication, ~2.5x latency speedup. => C2C is
  cache-as-communication-between-models; Uno is cache/weights-within-one-model for parallel decode.
  DIFFERENT axis, not competing: C2C's gate+fuser = the closest thing to the owner's "KV-cache
  communication protocol" and to a "typed-decision bridge" (the gate is a learned typed selector).

## PAGE 3 — citation: DFlash (arXiv 2602.06036) + Leviathan (arXiv 2211.17192)
- DFlash (MEASURED, PDF v1): "DFlash: Block Diffusion for Flash Speculative Decoding", Chen/Liang/Liu,
  project z-lab.ai/projects/dflash. Lightweight 5-layer BLOCK DIFFUSION draft model, drafts a block
  in ONE forward pass, conditioned on target-model context features; draft KV reused across blocks.
  >6x lossless acceleration; up to 2.5x > EAGLE-3; on Qwen3-8B 6.1x. Models for Qwen3-4B/8B,
  Qwen3-Coder-30B-A3B, LLaMA-3.1-8B. Experiments on a SINGLE B200. Uno's paper: DFlash drafter =
  1.05B params (~3x Uno's 0.35B), training context B*L vs Uno's 2L.
- Leviathan 2023 (MEASURED, abs): "Fast Inference from Transformers via Speculative Decoding",
  ICML 2023. The origin of lossless speculative decoding + rejection sampling; 2-3x on T5-XXL.
  Uno's Sec.4 cites its Corollary 3.6 for the distribution-preserving acceptance rule.

## VERDICT (this trove)
- Relevant to ALL FOUR owner threads: (1) KV-cache protocol -> C2C is the cited neighbour; Uno
  keeps KV inside one model. (2) typed-decision bridge -> not addressed; C2C gate is closest.
  (3) diffusion-augmented LLMs -> THIS IS THE PAPER. (4) oscillator/SNN readout -> NOT addressed;
  Uno is a drop-in weight trick, no oscillatory/spiking mechanism.
- Key transferable idea for the town: a 0.22-1.4 GB LoRA turns a frozen AR model into a
  multi-token drafter, losslessly. Tiny-model angle: K2-Horizon-0.9B is a real, Apache-2.0,
  ~1B-param AR model with a released Uno adapter.
