# mvp:a00-32e89a6b-035d14

## MVP

`extensions/agi/bin/adapters/grok_bot_adapter.py` now launches Grok into a
held, durable tmux pane. A first launch creates an empty session, sets the
pane-local `remain-on-exit on`, and then uses the same `respawn-pane -k` path
used by restart. Consequently a SIGKILLed agent leaves the session and pane id
resolvable; restart replaces only the pane process and observes a new pid.
`restart` also normalizes `subprocess.CalledProcessError` to its documented
`None` failure result.

## Inputs

The existing `args`, `cwd`, `env`, `log_file`, and optional record containing
`pane_id` and `pane_session`.

## Outputs

An `_TmuxProc` facade carrying the durable pane id, session, and observed live
pid. The record is stamped with pane identity and observation state.

## Evidence

`extensions/agi/tests/test_grok_bot_adapter.py` includes a real tmux test using
`sleep`: it records pane id/pid, kills the pid with SIGKILL, confirms the
session still exists, launches again, and asserts the same pane id with a new
live pid. The exact changed test file passed: 18 tests. Production diff was 13
added and 8 removed lines (measured with the permitted `git diff --numstat`).
