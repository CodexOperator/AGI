### The exact bytes changed

`extensions/agi/bin/cli.py`, `_rs_v3_local_post_source` (only call site is
the B2 gate at ~L4033; no other caller exists):

```python
    try:
        target = branches.derive_names(
            _rs_v3_core_town(tuples), season, name)["post_main"]
    except ValueError:
        return False
    # A branch that CARRIES an upstream is a real live migration, never a
    # v3-LOCAL post (whose local contract is upstream UNSET). `branch` is
    # usually GONE after the rename so its own probe is '' and the real
    # falsifier is `target`'s upstream — exactly the check the docstring
    # promised. Probe BOTH so neither spelling can slip through:
    # `_post_rename_upstream` is rc-honest ('' on a missing/dead branch).
    if _post_rename_upstream(repo, branch) \
            or _post_rename_upstream(repo, target):
        return False
    return _post_rename_has_branch(repo, target)
```

The docstring was updated to state the implemented mechanism (the upstream
check is now actually CALLED, on both `branch` and the derived `target`),
so it no longer describes a check the body does not perform. The mechanism is
a real upstream query (`_post_rename_upstream`, already rc-honest), never a
name-existence proxy. `branch` is usually GONE after the rename so its own
probe is `''`; the falsifier is `target`'s upstream.
