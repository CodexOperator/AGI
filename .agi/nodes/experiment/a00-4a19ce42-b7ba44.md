# experiment:a00-4a19ce42-b7ba44

## Experiment

Slice (4) of the target: two changes, one mechanism and one seam. `dispatch.py`
was NOT touched.

### 1. `cap_headroom` — headroom is what is SPENDABLE (mechanism, not refusal text)

Pre-fix, `extensions/agi/bin/provisioning.py` summed **every `agi-` key's FULL
limit**:

```python
live = sum(float(r["limit"]) for r in keys
           if str(r.get("name") or "").startswith(f"{NAME_PREFIX}-")
           and r.get("limit") is not None)
```

Nothing filtered on `disabled`, on `expires_at`, or on `usage`. The old refusal
clause ("live counts every agi- key's full limit; disabled, expired and
already-spent keys included") was the *disclosure* of that conservatism, not a
mechanism — so a spent or dead key permanently froze headroom it could not
spend.

Built, with two readable predicates instead of an inline pile:

- `_key_is_expired(rec)` — parses `expires_at` as ISO-8601; an **absent/None**
  `expires_at` is a key with NO TTL (the API's `expires_in_seconds` trap) and
  therefore NOT expired; an unparseable value is not expired either (fail-open
  on the time leg, never on a read that could not happen).
- `_live_key_headroom(rec)` — `max(0.0, limit - usage)` for a row that is
  engine-minted, non-`disabled`, un-expired and `limit is not None`; `0.0`
  otherwise. Absent/None `usage` is `0.0`.

`cap_headroom` now does `live = sum(_live_key_headroom(r) for r in keys)`.
`credit_balance`/`min_account_remaining_floor` handling and BOTH fail-open
markers are byte-for-byte as they were; only the *live* term changed meaning,
and the refusal clause was rewritten to match. The arithmetic shape of the
refusal (`pool - floor - live`, name all three) is unchanged.

### 2. `_run_cap_dispatch` — the missing grace seam

`test_dispatch.py::_run_cap_dispatch` stubs a child that never exits
(`_StubProc.poll() -> None`), so `dispatch.py:97-102` polls it through the real
`time.sleep` for the full 20 s startup grace. One monkeypatch line, same seam
as `1be791764` (already used at `test_dispatch.py:2666` for the startup-grace
test) fixes it:

```python
monkeypatch.setattr(dispatch, "_GRACE_SLEEP", lambda s: None)
```
