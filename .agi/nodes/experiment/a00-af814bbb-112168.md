# experiment:a00-af814bbb-112168

## Experiment

Build order for `hypothesis:grok-bot-live-config-row-has-a-pytest`: the
parent measured that the existing tests in
`extensions/agi/tests/test_grok_bot_adapter.py` were all SYNTHETIC --
`HARNESS` is a hand-built dict and every `resolve` test builds its `cfg` in
memory. No test read the real project `.agi/config.json`, so the suite would
stay green if the live `grok-bot` row vanished. The claim was therefore FALSE
before this run; this run makes it TRUE by adding the missing live-config
section (test-only, no production bytes).

### What was added

New labelled section `# --- live config row ---` in
`extensions/agi/tests/test_grok_bot_adapter.py`, four tests:

- `_project_root()` -- walks up `Path(__file__).resolve().parents` to the
  nearest ancestor holding `.agi/config.json`. No absolute path, no write to
  the config.
- `live_cfg` (module fixture) -- reads that file read-only via `json.loads`.
- `test_live_config_grok_row_resolves` -- `adapters.resolve(live_cfg,
  "grok-bot")` returns `name == "grok-bot"`, `row["adapter"] ==
  "grok_bot"`, and `row["bin"] == live_cfg["harnesses"]["grok-bot"]
  ["bin"]` (the LOADED cell, not a literal).
- `test_live_config_peers_still_resolve` -- `pi` resolves to adapter `pi` and
  `copilot-cli` to `copilot_cli`, no raise.
- `test_dispatch_still_has_zero_grok_hits` -- reads
  `extensions/agi/bin/dispatch.py` and asserts `"grok" not in text.lower()`.

Existing tests are untouched. Git measured the diff: 57 added lines, all in
the test file; `git diff --numstat` over production paths is empty, so
`production_lines: 0`.
