### Fix implemented (built bytes)
`extensions/agi/bin/rotate.py` — one new module helper `_spawn_behind_gate`
plus a call at the top of `cmd_spawn` (before the name derivation, before
`_first_seating_run` writes, before `spawn_window`):

* non-dry-run: `fetch origin <sb>` (the network write; the analogue is
  rotate-self's `perform=True` fetch at rotate.py check 3), then
  `rev-list --count HEAD..origin/<sb>`.
* behind > 0 and `_merge_applies_clean` True -> `_perform_season_merge`
  (the SAME two helpers rotate-self uses — no second merge implementation).
* behind > 0 and the merge conflicts / is unmeasurable / git refuses ->
  REFUSE BY NAME on stderr and return 3, **without launching**:
  `ERR: spawn refused: behind origin/<sb> N, merge conflict (<paths>); clear
  with: git fetch origin <sb> && git merge --no-edit origin/<sb>`
* `--dry-run`: measures behind with a local read only (no fetch), prints
  `[spawn] would merge origin/<sb> (N) (dry-run: no fetch, no merge)`, exits 0.
  No network write on the dry-run path (dispatch item 4).
* seat-less spawn (root given, no `--seat`) is in scope: the gate is outside
  the `seat is not None` branch, so the stale branch is caught with or
  without a seat. Tested (test 6 uses no seat).

`season_branch(root)` is the branch resolver, never a season literal.

### Tests
New file `extensions/agi/tests/test_spawn_behind.py`, 7 tests, git faked
through the existing `rotate._git_maybe` / `rotate._git_proc` seams:

1. behind + clean -> merge lands (`— merged cafe123`), rc 0.
2. behind + conflict -> rc 3, refusal names the path and the clear command,
   `_perform_season_merge` never called.
3. even -> no merge (the fetch is how "even" is learned), rc 0.
4. `--dry-run` behind -> would-line, rc 0, ZERO `_git_proc` calls (no fetch,
   no merge-tree, no merge).
5. merge gate says clean but git refuses the merge -> rc 3, never a false ok.
6. the real `cmd_spawn` returns 3 and `spawn_window` is never reached.
7. `cmd_spawn` source order: the gate call exists and precedes `spawn_window`.
