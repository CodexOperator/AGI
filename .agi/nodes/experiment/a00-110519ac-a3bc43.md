## ITEM 1 -- the stale deferred sidecar

Old bytes (send.py:4038-4042, `send_dm`):

```python

            and not _read_deferred(root, other) \
```

`_read_deferred` is a PRESENCE test, not a before/after test: a sidecar left by
an earlier, unrelated send suppresses the mark for this brand new dm whenever
the pane is gone -- the TMM.283 symptom for exactly that seat.

New bytes -- one before/after discipline for both sidecars, in a single choke
point both sender paths share:

```python
def _register_unresolved(root, seat, before_pending, before_deferred):
    if _row_is_quiet(root, seat):

        return
    if _pending_more(root, seat) != before_pending:
        return

```

this nudge (`_store_deferred` wrote the head, or appended to `others` and
counted the append at :2340 / :2495 / :2509). The red test that motivated the
old guard stays green -- `test_dm_deferred_under_busy_retries_inline` passes
unchanged, because that path DOES write the sidecar.
