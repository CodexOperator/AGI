### What was built

**(A) ONE clock — new `extensions/agi/bin/last_act.py` (149 lines).**
`stamp_path`/`touch`/`last_act_ts`/`card_stale`, plus `own_card`,
`card_commit_ts`, `_stamp_ts`, `_git`. Sessions resolved through the engine's
ONE resolver (`locations.shared_sessions_dir`), so the hook and rotate agree on
`<sessions>/seats/<seat>.last-act` from any worktree. `touch` never raises;
every reader fails open (P7).

**One documented DEVIATION from the briefed formula.** The brief says
`card_stale = card.stat().st_mtime < last_act_ts` with `last_act_ts` = newest of
(stamp, own card commit). Implemented literally, that reads STALE the instant the
card is committed: git's `%ct` is the commit's whole second and is `>=` the
write's mtime, so the card's own commit always appears to be an act after the
card — re-creating the loop this node removes. `card_stale` therefore treats the
card's OWN commit as the FLOOR: stale requires a LATER act (a stamp) than that
commit. Both briefed falsifiers still hold (a foreign commit never changes the
verdict; an own stamp after the card does).

**(B) Both call sites use the helper, and only it.**
- `rotation_alert.py:630 _work_last_ts(root, seat, card)` is kept as a NAME
  (the existing test monkeypatches it) and is now a thin wrapper over
  `last_act.last_act_ts`; the repo-wide `git log -1 --no-merges -- .` spec is
  gone. `:641 _card_stale_measure` passes that reading into
  `last_act.card_stale(..., last_ts=...)`, so the monkeypatched value is still
  what the verdict compares against.
- `rotate.py:15172` check 4 (`card older than last commit`) calls the SAME
  helper; the `stops_rotation` / `_ack_seats_path` exclusion is deleted as
  unnecessary (the clock is seat-scoped by construction).
- `grep -rn no-merges` on both files: only comments remain. The one live hit is
  `rotation_alert.py:721 _stops_line` (the displayed `stops: <subject>` text),
  which is NOT the card-age clock and was left alone.

**(C) Gate (b) fires only on a REAL merge in flight.** `_merge_in_flight`
(`rotation_alert.py:594`) now returns only `merge in progress on MAIN`
(MERGE_HEAD) or `verify-suite lock live` (a LIVE holder pid).
`_season_unpushed` is KEPT as a name (test_rotation_alert.py asserts on it) and
now delegates to a new `_season_unpushed_count` (`:573`); the count is MEASURED
and printed at `:900` as `info: N unpushed commit(s) on <branch> (not a merge in
flight)`, never a captive and never a `rotation deferred`.

**(D) Conjunct (4).** The gate (a) refusal prints the one-line exit FIRST
(`  rotate.py handoff --driven --seat <seat>`), then the prose; a test asserts
the index order.
