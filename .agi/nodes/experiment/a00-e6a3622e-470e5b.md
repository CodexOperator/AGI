# experiment:a00-e6a3622e-470e5b

## Experiment

**Goal:** Extend sibling `experiment:a00-af93633e-fea9ca` (context-search proxy) by modeling the FULL tool-call tradeoff — both internal context-search AND external tool calls (file reads, grep, ls). The sibling found briefing wins context-internal search 70% (1.0 vs 3.33 chunks). The question: can chat's richer disambiguation *eliminate enough external calls* to offset that overhead?

### Method

Monte Carlo simulation (N=1000 trials per regime, seed 42). Constants from sibling proxy:
- Chat internal search:    3.33 chunks (SD 1.18)
- Briefing internal search: 1.00 chunks (SD 0.00)
- External cost per call:  3.0 tool-call steps (grep pattern, read file, extract answer)

Three regimes test the hypothesis under increasingly generous assumptions:

| Regime | Briefing external prob | Chat external prob | Chat advantage |
|---|---|---|---|
| A (conservative) | 0.20 | 0.20 | None — both same |
| B (moderate) | 0.40 | 0.20 | Chat halves briefing's external-call rate |
| C (optimistic) | 0.45 | 0.15 | Chat eliminates 2/3 of briefing's external calls |

### Results

```

TRADEOFF PROXY: Chat vs Briefing — Total Tool-Call Model
========================================================================

--- REGIME A: conservative (chat eliminates 0 external calls) ---
  Briefing external prob:   0.20
  Chat external prob:       0.20
  Chat mean total:          3.90 ± 1.66
  Brief mean total:         1.53 ± 1.14
  Effect (brief - chat):    -2.37 steps (-155.0%)
  Cohen's d:                1.66

--- REGIME B: moderate (chat eliminates ~half of briefing's external calls) ---
  Briefing external prob:   0.40
  Chat external prob:       0.20
  Chat mean total:          3.88 ± 1.74
  Brief mean total:         2.25 ± 1.48
  Effect (brief - chat):    -1.62 steps (-72.0%)
  Cohen's d:                1.00
  → Briefing wins (fewer total steps)

--- REGIME C: optimistic (chat eliminates ~2/3 of briefing's external calls) ---
  Briefing external prob:   0.45
  Chat external prob:       0.15
  Chat mean total:          3.75 ± 1.55
  Brief mean total:         2.43 ± 1.50
  Effect (brief - chat):    -1.32 steps (-54.4%)
  Cohen's d:                0.87
  → Briefing wins (fewer total steps)
```

### Interpretation

**Briefing wins across ALL three regimes.** Even under the optimistic assumption (chat eliminates 2/3 of briefing's external-call burden), briefing's total steps remain 54.4% lower. The internal-search overhead from sibling proxy (2.33 extra chunks for chat) is so large that even generous external-call savings cannot offset it.

**Key threshold:** For chat to break even, an external call must cost >~7.3 steps (2.33 chunk gap × 3 steps/chunk) — or external calls must be nearly certain for briefing and zero for chat. Neither is realistic: grep + read typically costs 2-4 steps total, not 7+.

**What this means for the hypothesis:** The model disfavors it. Even the hypothesis's core claimed mechanism (richer chat context reduces external tool calls) is insufficient when modeled. The sibling proxy (context-search only, favoring briefing 70%) understated briefing's advantage — the full tradeoff model still favors briefing.

### Limitations

- Still a **simulation**, not real agent dispatch. Real LLMs have attention that may process long context differently than sequential scan.
- External-call probability and cost are fixed parameters. Real distributions vary by task complexity, node type, and model.
- Does not model the *cost threshold* where an agent gives up on context and switches to external search — that could shift the tradeoff.
- Assumes independence between internal and external costs; in practice, spending time on context may reduce *or increase* external search quality.
