### What landed (FILE SCOPE respected: rotate.py + heal.py + tests only)

1. `rotate.run_after_join(root, *, seat, gen, startup, values, record_path,
   dry_run, sleep_impl, delay_override, send_dm, ...)`: waits
   `startup.after_join_delay_s` (default 20), runs the template `after_join`
   list as ONE ordered flow (placeholder-resolved, no-shell, per-command
   timeout + byte cap — reuses the existing `_command_units` /
   `_run_units_no_shell` pair), writes every command's output into the
   rotation record (`after_join` key, so a second pass is idempotent), and
   sends ONE dm — the successor's SECOND input — whose decision is CAPTIVE
   (the exact copy-paste `diff` line). `sleep_impl` / `send_dm` injectable so
   no test waits or nudges a real pane.
2. `rotate.run_after_join_for_seat(root, seat)`: service-side discovery — the
   seat's latest rotation record that has NOT yet had its after_join run and
   is past its delay; reuses the SAME `run_after_join`. The joined
   `session_id` travels as the ack `--ref`.
3. `rotate._inline_reaper_enabled(root)`: reads
   `agent_dispatch.inline_reaper`; absent config defaults True (current
   behaviour unchanged).
4. **rotate-self fallback caller** — in `cmd_rotate_self`, after the success
   record write (6.4): when `_inline_reaper_enabled` is True (no service) it
   runs `run_after_join` post-spawn; when False (the live box) it defers to
   the service and says so; `--after-join` forces the fallback for a fixture.
   The dry-run branch enumerates the `after_join` plan (resolved, NOTHING run)
   and prints the captive line.
5. **heal.py service caller** — `heal._run_pending_after_joins(root)`, invoked
   from `_watch` each pass alongside wake repair, only when per-rotate
   `_inline_reaper_enabled` is False; calls the SAME
   `rotate.run_after_join_for_seat`. Read-only discovery, best-effort, never
   raises into the watch loop.
