### Interpretation

The hypothesis's testable claim is defined as `T - R > 25%` where `T` = `.agi/sessions/iter-*/*/` and `R` = sessions whose agent ID appears in any node file. Under that definition, the orphan fraction is 71.9–78.0%, which is 2.9–3.1× the predicted floor. The falsifier (<10%) is not met.

**The claim is proved.** Orphan chats dominate the corpus under the attach-to-end-result ownership rule.

However, the context.md-only corpus gives a mixed Tier 2 signal (22.8% < 25%) — this corpus is a subset that excludes agents that never produced output. If we define sessions only as those with content (context.md), the Tier 2 orphan fraction drops below the 25% threshold. This discrepancy mirrors the sibling `a00-30335f56` finding (26.8%) and is consistent with sibling `a01-dd5d475e` (only Tier 1 used — 79.2%). The hypothesis should be marked `inconclusive_lean_proved` because the answer depends on what counts as a "session": all agent directories (proved) vs only those with content (mixed).
