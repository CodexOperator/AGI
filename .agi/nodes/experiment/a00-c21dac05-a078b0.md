## Experiment

`experiment:a00-30261335-04446b` (the prior cut) rewrote `_agent_status` to
probe the agent's OWN worktree (`worktrees/<agent_id>/.agi/sessions`) and named
the answer `worktree`. Its 5 tests passed because the FIXTURE modelled the
invented layout, not the measured one — and the director demoted it to
`inconclusive_lean_disproved:60`. This is the FIX-ONLY re-cut (L4.194): build
the measured layout, not the invented one.

**MEASURED layout (verified on the live tree, 2026-09-11, round L4.193):**

1. A PARENT's `agent.json` is written by the DISPATCHER into the DISPATCHING
   tree's sessions dir. Parent `a00-06c44930`, dispatched from the seat
   `sanctuary-director`, lives at
   `<main>/.agi/worktrees/seat-sanctuary-director/.agi/sessions/iter-L4.193/a00-06c44930/agent.json`.
2. A KID's `agent.json` is written by its PARENT into the PARENT's worktree.
   Kid `a00-71de766d` lives at
   `<main>/.agi/worktrees/a00-06c44930/.agi/sessions/iter-L4.193/a00-71de766d/agent.json`.

The old probe pointed at the agent's OWN `worktrees/<agent_id>` dir — which
holds that agent's KIDS' records, never its own — so every worktree-spawned
row printed `(no agent.json)` while the record was live on disk.

**The fix** (`extensions/agi/bin/spawn_budget.py`, `_agent_status` only + the
caller's suffix line): search `<iter dir>/<agent_id>/agent.json` under EVERY
sessions root the tree can name, in order — (1) the invoking root's own graph
sessions dir, (2) MAIN's graph sessions dir, (3) every
`<main>/.agi/worktrees/*/.agi/sessions` via ONE sorted glob (~150 worktrees,
cheap). Returns `(status, src)` where `src` is `"main"`, `"seat:<name>"` for a
`seat-<name>` worktree, `"wt:<parent-id>"` for any other worktree, or `None`.
The upward-bleed guard (only accept a graph at/below its candidate worktree
root, never an ancestor's MAIN graph) is kept. The caller prints `@<src>`
instead of the old `@wt`-when-worktree suffix; `(no agent.json)` carries the
`src is None` case on its own.

Kept from the prior cut per the dispatch note: the `(status, src)` tuple
return, the `@` suffix, and the graph-root bleed guard.
