# experiment:a00-57f16627-9e9406

## Experiment

Implemented the fix the previous kid's measurement (experiment:a00-edfd2a9d-4b64c4)
demanded, scoped to `extensions/agi/bin/rotate.py` inside `_reap_belam_oldest`
(+ the shared `_kill_window`).

**The defect (measured by the prior kid):** `_reap_belam_oldest` returned EARLY
on BOTH skipped paths — rotation (no pane pid) and pane-pid-with-no-descendants —
BEFORE reaching `_kill_window(...)`, so the oldest window's @id line stayed in the
window file. A skipped Belam-cap reap left six windows, violating the FIFO-five cap.

**What I changed:**

1. `_kill_window` now RETURNS a status string — `"killed" | "already_gone" |
   "error"` — instead of `None`. On the window_path test seam it returns
   `"killed"` iff an owned line (@id or name) was dropped, `"already_gone"` when
   there was nothing to drop. On real tmux it inspects stderr for
   `can't find window` / `no such window` / `can't find session` → `"already_gone"`.
   It never raises; a thrown tmux returns `"error"`.

2. Inside `_reap_belam_oldest`, added a `_kill_oldest_by_id()` helper: on a
   SKIPPED path with an @id available it still kills the oldest window BY @id
   before returning; when `oldest_id` is None it records `window_killed: false`
   and does NOT call tmux.

3. BOTH skipped branches now record `window_id` and `window_killed` alongside the
   existing `skipped` named reason. When `_kill_window` reports the window already
   gone, the `skipped` text carries the phrase `already gone` (never an error).

4. The reap-by-PID (success) path is unchanged.

**Tests added** to `extensions/agi/tests/test_rotate_handover.py` (all on the
window-file seam, real `_kill_window` write-out):
 - (a) no pane pid → the oldest `@9 belam-S1-L4-I` line is GONE from the window
   file, record has `window_id == "@9"` and `window_killed is True`.
 - (b) pane pid with no descendants → same, `window_id == "@9"` resolved, line
   gone, no raise.
 - (c) window already gone (monkeypatched `_successor_window_id` returns `@9` but
   the file lacks it) → record's `skipped` carries `already gone`,
   `window_killed is False`, no exception.
 - each asserts the surviving window-file chain count is `<= 5` (falsifier: a
   skipped cap leaving six).
