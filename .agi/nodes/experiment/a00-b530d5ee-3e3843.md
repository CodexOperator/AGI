## Experiment

Built hypothesis:l4-every-pi-kid-keeps-its-full-tool-call-trajectory-at-spawn-never-pruned-never-rebuilt. First DISPROVED conjunct 1's easy route: the pi session store (`~/.pi/agent/sessions/`) prunes tool RESULTS (parent-verified, 129 files, zero `tool_use`/`tool_result`), so the trajectory must be caught at the process boundary. The crux (parent section 3): **dispatch.py exits right after spawn** (inline reaper off by default — `reaper: inline reaper off` when `agent_dispatch.inline_reaper` is false), so a parent-process tee thread cannot survive; the capturer must be a process with pi's lifetime.

The only such process is a child dispatch spawns IN PLACE of pi. So `pi_adapter.build_command` now returns a WRAPPER's argv (`pi_trajectory.py --wrapper <pi-bin> <trajectory.jsonl> -- [real pi args...]`) instead of bare pi's, and adds `--mode json` to the real args. The wrapper runs real pi under `--mode json` (parent-verified event stream: `tool_execution_start`/`update`/`end` with `toolName`, `args`, `result`, `timestamp`), tees pi's stdout to output.log (dispatch still redirects the wrapper's stdout there), parses each `tool_execution_end` into ONE ordered jsonl record `{ts, tool, args, result, isError}` on trajectory.jsonl as it arrives, forwards SIGTERM/SIGINT to pi, and exits with pi's exit code. `dispatch.py` is UNCHANGED — the wiring is entirely a different argv, so no spawn/restart/reaper/death-classification consumer moves. `cli.py session-complete` was already a whole-subtree copy (`_migratable` = everything except `.manifest.lock`), so trajectory.jsonl rides home by construction; I did NOT touch it, only proven it.

Files: NEW `extensions/agi/bin/pi_trajectory.py` (wrapper, ~71 lines — the parent's "new small module in scope"); `pi_adapter.py` (+`-p --mode json`, + wrapper-argv return, +`import sys`) = **20** production lines by `git diff --numstat` (under the 40 ceiling / 80 tripwire; the untracked new module would add ~71 more). FAILURE semantics: a trajectory path that cannot open — or a write that raises — yields ONE named line `trajectory: not captured: <reason>` on output.log, never silence, never a fabricated/truncated record (`_failed` guard = at most one).
