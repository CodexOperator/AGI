# experiment:a00-f4e71f5c-47a692 — propose: validate and return, never execute

## Experiment

Built the **last conjunct** of `hypothesis:commands-manifest-is-jevs-one-choice-surface`:
`propose` in Python, as `commands.py propose`, and over graphweb's stdlib server
(`GET /commands.json` + `POST /propose`). No argv entry, no `command:commands`
entry and no existing `commands:` command was renamed or edited — this round only
ADDS a reader/validator over the 133-entry manifest KID 2 finished.

Changed files (production):

- `extensions/agi/bin/commands.py` — `_coerce` + `propose(root, name, args)`;
  `propose` added to the CLI action choices and a `--args` JSON option. `propose`
  looks the name up in `manifest(root)`, refuses by NAME when absent or
  `proposable: false`, validates each declared arg (required present, value in
  `choices` when non-empty, declared `type` coerced), substitutes values into the
  argv template (compound tokens included), and RETURNS the argv list. It calls
  no subprocess and writes nothing.
- `extensions/agi/bin/graphweb.py` — `import commands`; `_json` gained an
  optional `status` (default 200, unchanged for existing callers);
  `GET /commands.json` returns `commands.manifest(root)`; new `do_POST` answers
  `POST /propose` with `{"argv": [...]}` or a 400 whose body is
  `{"error": <reason>}`. `serve` is untouched: still `127.0.0.1` by default.
- tests: `extensions/agi/tests/test_commands_manifest.py` (8 propose tests) and
  `extensions/agi/tests/test_graphweb.py` (3 HTTP tests).

  `127.0.0.1`.

### Deviation, disclosed

`propose` substitutes a value only for a placeholder spelled `<argname>`. Where
the declaration's placeholder is not the arg's name — `write.py:read` declares
`range` but its argv token is `"read <target> <N:M>"` — the `<N:M>` token is left
in the returned argv rather than silently guessed. `write.py:set`'s compound
token `"set <key> <value>"` is the case the brief names and it substitutes fully.
A caller may still fill any non-schema placeholder (`<node-id>`) by passing that
key in `args`; extras are substituted but never validated.

### Falsifiers not tripped

No `command:commands` entry or `commands:` argv was edited (`git diff` touches
only `commands.py` + `graphweb.py` production paths). propose (Python, CLI, HTTP)
spawns no process and writes no file. `/commands.json` and `/propose` are served
by the existing localhost-only `serve`; no second bind was introduced.
