# experiment:a00-02b4b957-5fdb49

## Experiment

BUILD ORDER (goal:g15.25 re-cut, Prime XIX 07:28Z ruling, in the parent's
`## Agent Notes`): the ROW is the ONE source for the launch
model/effort/settings at the two launch sites. A `--model`/`--effort`/
`--settings` that DIFFERS from the row cell is refused by name (exit 3,
nothing launched); a flag equal to the row is a no-op; `--dry-run` prints
the same would-refuse line and touches nothing. The pre-re-cut "flag writes
itself into the row" claim and `--no-row-write` are withdrawn.

Implemented in `extensions/agi/bin/rotate.py`:
- Added shared helper `_row_launch_refusal(args, row)` (before `cmd_spawn`) —
  refuses model/effort/settings against the row cell, returns the refusal
  line naming the flag AND the row value in the required shape.
- `cmd_spawn` (row resolve, ~L1933): after `_srow = _find_seat(...)`, a
  differing flag prints `--model opus differs from the row: model sonnet; the
  row changes only through write.py by the Prime/owner ahead of the rotation`
  to stderr and returns 3 — before any write or launch.
- `cmd_rotate_self` (row resolve, ~L17568): same refusal after the row block,
  guarded by `if row:` so a THROWAWAY (rehearsal default row, no authoritative
  cell) is left to the ladder inside spawn_window.
- The `expected_model` poll (~L18801) already reads the row in every reachable
  state: a differing flag can no longer reach it.
- Kept the existing launch precedence (`args.model or row...`) — the refusal
  makes a differing flag unreachable, so the surviving value is the row.

Updated `extensions/agi/tests/test_rotate.py` `test_spawn_seat_row_is_the_model_
source_flags_only_override`: its middle branch asserted the WITHDRAWN
"explicit flags override the row" behaviour — rewritten to the re-cut
(differing flag -> rc 3, nothing launched; equal flag -> proceeds on the row).
