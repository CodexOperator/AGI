## Experiment

The falsifier at the PRODUCTION restart call site, on the bytes this round
landed (real tmux server, throwaway session `hold-prod-a00-603fb228`).

Driver: `.agi/sessions/iter-DH.90/a00-603fb228/exp/run_prod_restart.py`
(full capture `exp/capture.txt`). Negative control:
`exp/run_neg_control.py` (`exp/capture_neg.txt`).

Sequence: `tmux_hold.spawn` (the first-spawn seam `dispatch._open_round` now
calls) -> `kill -9 <pane_pid>` -> `grok_bot_adapter.restart(...)` -> compare
`tmux list-panes -s` BEFORE / MID / AFTER.

Captured bytes (verbatim):

```
BEFORE (first spawn): seat-eef482ff8484 %0 4106230
$ kill -9 4106230   rc=0
proc_alive(4106230) = False
MID (process dead, pane held): seat-eef482ff8484 %0 4106230
grok_bot_adapter.restart returned pid=4106507 record.tmux={'created': False, 'pane_id': '%0'}
AFTER (production restart): seat-eef482ff8484 %0 4106507
ALL ASSERTIONS PASSED: same window, same pane_id, churned pane_pid, created=False
```

Negative control (genuinely destroyed window):

```
BEFORE: seat-ffd9b0c33d17 %0 4148480
$ tmux kill-window -t %0   rc=0
GONE (window destroyed): None
reattach pid=4148618 created={'created': True, 'pane_id': '%0'}
REBUILT: seat-ffd9b0c33d17 %0 4148618
```

**Finding.** tmux REUSED the freed `#{pane_id}`: the destroyed `%0` was rebuilt
into `%0`. Pane-id novelty is therefore not a reliable held/rebuilt
discriminator; `created=True/False` is. The held-path claim (same pane id
across a real process death) is unaffected.

Fake-tmux regression guard (no real tmux; conftest `_no_real_tmux` in force):
`python3 -m pytest extensions/agi/tests/test_tmux_hold.py
extensions/agi/tests/test_grok_bot_adapter.py -q` -> 27 passed.

## Result

`kill -9`. This is the goal's falsifier, green on the built bytes.
