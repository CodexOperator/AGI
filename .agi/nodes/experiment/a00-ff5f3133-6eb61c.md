# experiment:a00-ff5f3133-6eb61c

## Experiment

This is a goal:g15 BUILD ORDER, not a measurement: measured the pre-fix
state, implemented the fix, proved it on the built bytes.

**Pre-fix state (measured).** `_rename_surfaces` (rotate.py:3553) resolved
every session-file surface through `_sessions_dir(root)` (rotate.py:309) ->
`locations.shared_sessions_dir` -> `git_common_root` -> MAIN's
`.agi/sessions/`, so a rotation-with-rename from a post's OWN worktree
renamed MAIN's `quorum/<old>.md`. The successor brief that `spawn_window`
resolves (rotate.py:1767, `Path(prompt_file).expanduser().resolve()`) is
CWD-relative -- and a worktree post's cwd IS its worktree
(`hypothesis:l4-spawn-cds-into-the-row-worktree-cell-when-set`) -- so it
looked for `<wt>/.agi/sessions/quorum/<new>.md` while the boundary had
renamed MAIN's copy: `ERR: prompt file not found`, exit 1 (the 19:08Z
recovery incident).

Pre-fix failure (probe in the scratch dir, `/tmp/agi-l511-probe/prefix.py`,
with `_own_sessions_dir` forced back to the pre-fix `_sessions_dir` rule):
```
AssertionError: PRE-FIX FAIL:
  got      '/tmp/agi-l511-probe/prefix/graph/sessions/quorum/old.md',
  expected '/tmp/agi-l511-probe/prefix/post-old/.agi/sessions/quorum/old.md'
```

**Root measurement (file:line).** The quorum CARD is the seat's OWN file.
`_own_card_path` (rotate.py:7532) returns `Path(root)/"sessions"/"quorum"/
<S>.md` then `Path(root)/".agi"/...` FIRST, falling back to `_sessions_dir`
(MAIN) "only when no own copy exists". Its check-4 caller (rotate.py:15775-
15779) spells it out: "The card lives in the SEAT'S OWN tree
(`<worktree>/.agi/sessions/quorum/<seat>.md`, committed on the seat
branch); `_sessions_dir` routes to the shared MAIN checkout, whose copy
only moves at merge-up -- measured at gen I's rotation: the live check read
MAIN's stale copy and blocked a clean rotate-self". `cmd_handoff` writes
that same path via `_own_card_path` (rotate.py:7848). So option (B) is the
measurement-supported fix: the RENAME moves to the worktree card, the brief
stays where it already resolved (CWD = the worktree). Option (A) re-pointing
the brief at MAIN would have fed the successor MAIN's stale card and
disagreed with `_own_card_path`.

**The fix.** New `_own_sessions_dir(root, seat)` (rotate.py, above
`_rename_surfaces`): the tree the post itself lives in, chosen from the seat
ROW's `worktree` cell (resolved against `locations.git_common_root(root)` when
relative, the same rule `_prepare_merge_target` uses to partition MAIN posts
from worktree posts), falling back to `_sessions_dir(root)` when the cell is
empty/absent or the dir does not exist. `_rename_surfaces` now uses it for the
`quorum` sub-glob only. `spawn_window`'s not-found refusal now names the
resolved path and the root it resolved against, never a bare
`prompt file not found`.

## Surfaces moved (by name)

- `session-file` surfaces under `sessions/quorum/<old>*` -> the post's own
tree (`<row worktree>/.agi/sessions/quorum/`). This is the card the successor
brief resolves and `_own_card_path` writes. Proved by tests 1 and 3 below.

Deliberately LEFT MAIN-rooted, with the reason:

- `sessions/<old>*` top level (`<old>.meter` pin, `<old>.log` debug, acks) --
  the SHARED room; `_seat_pin_path` (rotate.py) reads it through
  `_sessions_dir`, and the docstring says the pins must stay ONE directory.
- `sessions/seats/<old>*` (`<old>.handoff.md`, `<old>.key`) -- `_seat_hands`
  (rotate.py:4960) is `_sessions_dir(root)/"seats"`; the handoff is shared.
- `sessions/inbox/<old>*` -- `send._inbox_dir` is the shared room.
- dm logs -- unchanged: `_dm_participants` (rotate.py:3354) already resolves
  `Path(root)/"comms"`, the invoking tree.
- `seam-git` / `seam-tmux` branch/worktree/window surfaces -- unchanged.
