# experiment:a00-90e4dbe7-c48463

## Experiment

Tested the claim that a `--branch` round's session dir lives in TWO trees at
once, so bringing it home is a MERGE, not a copy. Implemented that merge in
`extensions/agi/bin/cli.py`'s `_session_complete` and proved it with four new
fixture tests while all nine of L4.66's existing tests stayed byte-unchanged
and green.

**What I changed** (`cli.py`):
- Gathered ALL candidate sources for an iteration up front, then treated the
  round as ONE logical unit: if ANY source is live or incomplete, the WHOLE
  round refuses (`refused_any`), so a half-finished round can never arrive in
  halves.
- `_merge_plan` builds the merge: a file held by one source is copied; a path
  held by two or more is a CONFLICT decided by content semantics — never by
  scan/iteration order. For an `agent.json` the more-terminal record wins
  (`done` > `done-unreported`, because the agent's own `cli.py done` is the
  actor speaking for itself while `done-unreported` is the reaper guessing the
  report was lost); any other path falls to the lexicographically smallest
  worktree slug. The LOSER is never deleted — it is preserved recoverably at
  `target/.conflicts/<rel>.from-<slug>`.
- Verification is two-tier: `_merge_verified` confirms every byte from every
  source is present (winner at `rel`, loser at its `.conflicts` path) before
  ANY source goes; then each source is removed only when ITS OWN contribution
  verifies (`_source_landed`), not when the target merely exists.
- All four L4.66 refusals stand: incomplete refuses, live lease refuses, a
  non-empty target (content that is not one of this round's own sources)
  refuses, `--dry-run` writes nothing, and a failed verify leaves the source
  intact.

**Result:** `13 passed` in `test_session_complete.py` (9 existing + 4 new),
and the required trio `test_session_complete.py test_cli.py test_dispatch.py`
is `113 passed`. I did NOT run the full suite (forbidden by the brief and by
the harness) and did NOT run `session-complete` against the live tree (other
seats are dispatching), per the exact constraint in the hypothesis.
