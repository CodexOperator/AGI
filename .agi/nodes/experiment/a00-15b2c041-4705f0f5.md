# experiment:a00-15b2c041-4705f0f5

## What was run

The residue named by the parent (`goal:g7.28.1` conjunct 2, parent probe C2b)
against the built bytes of `extensions/agi/bin/dispatch.py`.

**The one-line build.** `dispatch.py:2989` passed raw `args.seat` into
`_supervise_persistent`. When the seat comes from the INHERITED env (`AGI_SEAT`
set, no `--seat`), `_resolved_seat(args.seat)` resolves it (dispatch.py:322,
`--seat` wins, else `geometry_config.resolved_seat_env()`), but the raw value
is `None` -- so `_seat_row_pid` returns early (dispatch.py:1518, `not seat`)
and the row is never written. Built: `seat=_resolved_seat(args.seat)` -- the
same resolver already used for `spawn_env` (dispatch.py:2648) and
`dispatched_by` (dispatch.py:2861), no second resolver.

## Evidence

**(1) End-to-end against a REAL `config:posts` row**, on the exact path C2b
falsified -- inherited `AGI_SEAT`, no `--seat`. The tmp graph carries a
`posts:` row for seat `s-env`; the test reads the row back from disk *while
the child is held* (a `_PERSIST_SLEEP` hook reads it, then releases), and
again after release:

```
python3 -m pytest extensions/agi/tests/test_dispatch_persistent.py -q
5 passed, 7 warnings in 241.94s (0:04:01)
```

The new test `test_inherited_seat_writes_the_real_posts_row` asserts the live
row pid equals the held child's pid, and the row is the sentinel `0` after
release. It exercises the REAL writer (`rotate._write_identity_cells` ->
`write.submit`) and the REAL row, not a monkeypatched writer.

**Negative control.** With the call site reverted to raw `args.seat`, the same
probe fails:

```
1 failed, 1 warning in 140.56s (0:02:20)
```

so the test bites the C2b defect rather than the fixture.

**(2) Regression surface** (unchanged from kid 1, re-run on this tree):

```
python3 -m pytest extensions/agi/tests/test_dispatch.py \
    extensions/agi/tests/test_dispatch_transient_respawn.py -q
145 passed, 16 warnings in 412.11s (0:06:52)
```

**Production diff:** 1 added / 1 removed in `extensions/agi/bin/dispatch.py`
(`git diff --numstat`; tests excluded) -- well under the 40-line ceiling.

## What this proves (and does not)

The inherited-seat hole is closed: a `--persistent` spawn whose seat comes
from `AGI_SEAT`/`AGI_POST` now writes the live pid into the seat's real
`config:posts` row and clears it to `0` on release, through the ONE registry
writer. A truly live end-to-end seat spawn (a real model child, a real
main-checkout graph) is still not exercised -- the fake child and the tmp
`.agi` are the boundary; the row semantics themselves are the real ones.
