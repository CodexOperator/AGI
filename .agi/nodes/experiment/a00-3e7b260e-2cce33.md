## ITEM 4 (highest priority) — FIXED IN BYTES. Option (b) taken.

`node_writer.writer_key_shape` refused `on / off / yes / no / true / false /
null / nil` because its own `yaml` round-trip returns the key as a Python
`bool`/`None`, so `list(back) == [k]` failed. But `write.py <node> 'set on
<v>'` renders `on: <v>` — the writer emits exactly that line. So a field the
**sanctioned writer wrote** was classified as off-shape, and the repair path
touched it.

Measured, not assumed — `.agi/sessions/iter-DH.574/a00-3e7b260e/probe_item4.py`
runs the same `_ensure_frontmatter` on the same tmp node twice, the pre-fix
predicate restored by monkeypatch, then the shipped one:

```
--- PRE-FIX (list(back) == [k]): ok=False msg="TypeError: '<' not supported between instances of 'str' and 'bool'"
---
id: experiment:e1
type: experiment
on: yes
parents: ['hypothesis:h1']
mint_id: abc
---

b

--- POST-FIX (this round): ok=True msg='frontmatter ok'
---
id: experiment:e1
type: experiment
on: yes
parents: ['hypothesis:h1']
mint_id: abc
---

b
```

**The damage is a hard block, not (yet) a deletion, and the exact chain is
worth recording.** `_off_shape_keys` returns `[str(k) …]`, so for the parsed
key `True` it hands back the STRING `"True"`; `new_fm.pop("True")` therefore
removes nothing — the real `True` key stays in the mapping — and
`render_frontmatter`'s `sorted(k for k in fm …)` then raises `TypeError:
'<' not supported between instances of 'str' and 'bool'`. Every `done` on such
a node dies. The `pop` is a *no-op that preserves the crash*: the brief's
silent-data-loss reading is right about intent and wrong about today's
byte-level effect.

**The decision, stated explicitly.** I took **(b)**: the predicate is wrong for
the YAML-1.1 boolean/null words, and the round-trip must compare the key **as
the writer rendered it**, not as the reader re-parsed it. A key the
sanctioned writer demonstrably emits is in the writer's shape by definition;
only the resolver's collapse is forgiven, and only to a scalar it cannot
spell.

```python
    if not isinstance(back, dict) or list(back.values()) != ["x"]:
        return False
    got = next(iter(back))
    if got == k:
        return True
    return isinstance(got, (bool, type(None))) and not isinstance(k, (bool, type(None)))
```

**The near miss I avoided — option (a) read as plausible and is WRONG here.**
Refusing the node by name instead of `pop`ping is the brief's recommended
fallback when both are defensible. For this family it is not merely
conservative, it is a **false refusal**: the pre-fix probe above *is* the (a)
behaviour, and it is the behaviour that blocks the node. (a) would have turned
a repairable legal write into a hard stop and left the 14 live hand-appended
nodes — the ones the round exists to repair — no better off. Its real value
is on the *other* key family (`probes=["wire`), where the block genuinely is
unrepairable as written; that path is untouched.

**Residual, honestly named:** the key SPELLING is not preserved across a
rewrite. The reader hands the writer `True: True` for `on: yes`, so any
re-render emits `True: true`. On this path the repair happens to leave the
block byte-identical, so nothing is observed — but the spelling loss is real
and lives in the frontmatter **reader** (`graph_core/persistence/frontmatter`),
which is OUTSIDE FILE SCOPE. Named for the director below.
