## Result

- Process death: `kill -9 3994495` → the pane `%175` is still listed, window
  name unchanged, `proc_alive=False`. The pane outlives its process
  (`remain-on-exit on`).
- Reattach: same window name `seat-495299a91a03`, **same `#{pane_id}` `%175`**,
  new `#{pane_pid}` 3994513, `created=False`. A second reattach is the same
  (`%175`, 3994529, `created=False`).
- Negative control: after a real `kill-window`, the pane is gone; reattach
  re-creates it exactly once with a **new** `#{pane_id}` `%176` and
  `created=True` — so the `created` flag distinguishes a held pane from a
  fabricated one.

`#{pane_pid}` churns 3994495 → 3994513 → 3994529 → 3994567 while `#{pane_id}`
is stable — the process-independent seat occupation `goal:g7.31.1.2` asks for.
