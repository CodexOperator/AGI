# experiment:a00-a418da8b-38e800-exp

## What was exercised

Added a focused live-process regression test to
`extensions/agi/tests/test_real_adapter_restart.py`. It invokes
`pi_adapter.restart()` with a real `subprocess.Popen`, a credential-none
harness, and a recorder executable that writes the value of
`OPENROUTER_API_KEY` from the child process environment. The test waits for
that marker and requires the sentinel `<absent>`, so it exercises the spawned
process rather than merely inspecting Popen kwargs.

## Evidence

- Focused suite: `14 passed` in `test_real_adapter_restart.py`.
- Positive probe: the real restarted child writes `<absent>`, proving the
  restart path routes through `child_env` and removes the inherited key for
  `credential: "none"`.
- Negative control: existing tests cover the opposite direction and the live
  dispatch record seam; the existing unmarked-row restart test retains the
  inherited key, and the new test would fail if the recorder received it.
- No production bytes changed: `git diff --numstat` measured 0 production
  lines and 36 added test lines.

## Scope / limits

This checkout contains no `tmux_hold` implementation or reattach seam by that
name, so that part of the parent claim could not be exercised here. The
restart environment seam is covered directly; tmux hold propagation remains
for a child with access to the relevant pane launcher.

## Verdict

The tested restart/environment conjunct is proved on the real process path;
the broader parent claim remains only partially evidenced because the named
tmux hold surface is absent from this checkout.
