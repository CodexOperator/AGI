# experiment:a00-d43af693-c3e95f

## What I did

Forked from `experiment:a00-64458239-a39944` (verdict=proved) on its parent's
review, which found that **the committed falsifier does not falsify**: both
committed tests call `dispatch._reap_one_impl(...)` WITHOUT `cap=`, so `cap`
takes its DEFAULT of 1 (dispatch.py:3455) while the rig holds exactly one
occupant lease. The GLOBAL bound refuses the restart (`live=1 >= cap=1`) and
the `pi-local` row check is never reached.

So the whole pre-fix/post-fix distinction rested on one stderr substring.
This experiment repairs the falsifier and re-measures the claim on bytes that
can actually go red.

**Change (test-only, `extensions/agi/tests/test_restart_harness_live_bound.py`):**

| where | what | why |
|---|---|---|
| `GLOBAL_CAP = 25` + module comment | the global cap is stated by the test, not inherited from a default that equals the row's `max_live: 1` | the two bounds must be told apart to test either |
| `_reap(graph, iter_dir, adapter, rec, agent_id)` | one helper that threads `cap=GLOBAL_CAP` AND `cfg` on every reap | `cfg` and `cap` are the two ways the global bound can pre-empt the row; a future edit that drops either fails loudly here |
| test 1, new assertion | `assert spawn_budget.live_count(graph) < GLOBAL_CAP` before the reap | the test states that the global bound is NOT the binding constraint, so a refusal can only be the row |
| docstring | names the `cap=1` default trap | the trap outlives this file's next edit |

No production line changed: `git diff --numstat` over `extensions skills src`
(excluding tests) is **empty — 0 production lines**, ceiling 40.
