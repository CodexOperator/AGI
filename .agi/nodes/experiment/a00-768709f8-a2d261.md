# experiment:a00-768709f8-a2d261

## Experiment

Verified whether spawned dispatch process argv carries tier-specific model identifier detectable by `ps`-level inspection, per hypothesis `a00-373ec687-7bb58a`.

**Config A (correct tiering):**
- Parent model: `qwen/qwen3.8-27b`
- Kid model: `deepseek/deepseek-v4-flash`
- Distinct models configured in `config.json` `harnesses.pi.models`

**Config B (tier escape):**
- Parent and kid both set to `deepseek/deepseek-v4-flash` (simulating fallback where only one model available)

**Tests:**
1. Code analysis: `pi_adapter.py.build_command()` -> `model_args()` generates `--model <tier_model>` in argv.
2. Live /proc verification: spawned process with `--model qwen/qwen3.8-27b` flag visible in `/proc/PID/cmdline`.

## Evidence

### Code: model flag in argv (Config A, parent tier)
```
pi --provider openrouter --model qwen/qwen3.8-27b --thinking medium -p ...
```

### Code: model flag in argv (Config A, kid tier)
```
pi --provider openrouter --model deepseek/deepseek-v4-flash --thinking medium -p ...
```

### /proc/PID/cmdline verification (live process)
```
$ python3 /tmp/testsleep.py --model qwen/qwen3.8-27b --provider openrouter
$ tr '\0' ' ' < /proc/$PID/cmdline
python3 /tmp/testsleep.py --model qwen/qwen3.8-27b --provider openrouter
# --model qwen/qwen3.8-27b DETECTED in cmdline
```

### Tier escape detection (Config B)
```
Parent argv:   --model deepseek/deepseek-v4-flash
Kid argv:      --model deepseek/deepseek-v4-flash
Parent expected qwen/qwen3.8-27b, got deepseek/deepseek-v4-flash
-> Inspection correctly flags tier escape
```

### Derived properties
- Model identifier determined at spawn time from `--tier` arg -> order-independently correct
- `/proc/PID/cmdline` is external (set at `execve(2)`, cannot be forged by process)

### Caveats
- argv model flag is the *requested* model at launch, not proof the LLM call used that model. Process could switch models at runtime.
- Verified the `pi` harness only. `claude-code` harness uses a different adapter.

### Commands run
```

```
