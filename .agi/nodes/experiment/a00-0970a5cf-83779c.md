## Experiment

Implemented the SIBLING before-work stall shape in `extensions/agi/bin/`
`stall_detect.py` as a parallel judgment path, NOT a widening of L4.78's
`detect_stalled` four-parameter AND (its signature, docstring and tests
untouched):

- `detect_stalled_before_work(*, zero_kids, record_status, worktree_clean,
  age_s, threshold_s)` — pure judgment, returns bool, no side effects.
- `_cohort_zero_kids(agent_ids, exclude)` — condition (1): the parent spawned
  ZERO kids, genuinely none ever. Deliberately distinct from `_cohort_terminal`,
  which returns True VACUOUSLY over an empty set (that is precisely why L4.77
  escaped L4.78's detector).
- `_worktree_clean(rec, itdir)` — condition (3): INVERSE of L4.78's
  `_worktree_dirty`; `git status --porcelain` empty. Conservative on error:
  if cleanliness cannot be determined, returns False rather than risk a
  false liveness alarm.
- `scan_iteration_before_work` (read-only) and
  `record_stalled_before_work_in_iteration` / `note_stalled_before_work` (the
  one stamp) — mirror the after-work wiring, plus a `--before-work` flag on
  the `main()` CLI operator surface.

Constants: `STALL_BEFORE_WORK_THRESHOLD_S = 15 * 60` (15 min — the assigning
  director's operational rule, the reference point the brief offered; that
  rule is about when a human should ACT, this threshold is about when the
  state is worth RECORDING, the same distinction L4.78's 45-min T draws).
`STALL_BEFORE_WORK_LABEL = "stalled_before_work"` — a DISTINCT label (see
THOUGHT).

mirroring L4.78's discipline exactly:
- (a) all-four fixture IS detected (unit + scan + hook).
- (b) four fixtures each missing exactly ONE condition, NONE detected — one
  test per missing condition (unit: `test_spawned_kid_not_detected` /
  `test_non_running_record_not_detected` / `test_dirty_worktree_not_detected`
  / `test_young_not_detected`; scan-level too: any-spawned-kid,
  non-running, dirty, young).

  also stays out — both sibling labels remain lease-holding).
- (d) NOTHING is killed/restarted/committed when it fires — asserted on the
