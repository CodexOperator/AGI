# CFG.01 rebrief correction: namespaced box-root-relative paths, absolute roots reverted to literals

Kid of `hypothesis:lm-every-experiment-path-is-a-config-variable`, correcting the
`configuration` half the rebrief (director-thought, TMM.42) landed wrong in
`experiment:a00-1b4d6db0-04de8a`: it added an un-namespaced `paths` block with
ABSOLUTE values and a reader that anchored relative values at the nearest
`.agi`. This round implements the rebrief exactly and proves each resolved
value is byte-identical to the literal it replaced.

## What changed

1. **Config** `.agi/config.json` — the whole `paths` block is replaced by
   `paths.local_maxxing`. Every value is repo-relative or a placeholder; **no
   value is absolute** (asserted).
2. **Reader** `.agi/context/local-maxxing/paths.py` (town tooling, never under
   `extensions/`) — renamed to one reader callable by `.py` and `.sh`:
   - reads `paths.local_maxxing.<key>`;
   - substitutes `{root}` (= `box.root`) and every string cell of `locations.*`
     / `box.*` under its bare name (`{pi_home}`, `{claude_home}`, `{root}`);
   - after substitution an ABSOLUTE value is returned unchanged, a RELATIVE one
     is joined onto **`box.root`** (never the nearest `.agi`, never cwd);
   - unknown key -> message on stderr, exit 1; CLI prints the value.
3. **Reverted 6 scripts** whose only path was an absolute box root. The box
   root is NOT a `paths` value; the literal is restored and a `box` cell is
   proposed instead.
4. **Kept 3 converted scripts** (repo-relative worktree/session paths) and
   **converted `datasets/kid-sft/build_corpus.py`**.
