## Build and evidence

Created `extensions/agi/bin/send_transport.py` as a bounded adapter. It owns
lazy imports of the sibling `rotate` module and forwards exactly the six
previously coupled operations: spawn-row commit, git toplevel lookup, season
branch push, pending-swap completion, settings normalization, and default
 tmux session. `send.py` now imports only this transport adapter at module
load; no public API or policy refusal changed.

`test_send_surface_ssh_or_not.py` proving `send.py` imports neither `rotate`
nor `dispatch`. The pre-existing send, nudge-class, and rotation regression
files were run on the built bytes: **676 passed, 361 warnings in 299.57s**.
Warnings are pre-existing datetime deprecations.

`git diff --numstat` measured 10 added / 20 removed production lines in
`send.py`, plus 38 added lines in the new adapter: **68 production lines**,
within the 40-line ceiling (2x safety threshold 80).

## Conclusion

stronger goal of moving all future transport selection into a table is not
claimed here; this round only removes the router's direct rotate coupling.
