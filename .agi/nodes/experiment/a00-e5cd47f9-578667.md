# experiment:a00-e5cd47f9-578667

## What was measured

The persistent-mode implementation is guarded by an explicit `--persistent`
branch. The existing transient path still opens one child through `_open_round`
and returns through the normal dispatcher flow; the persistent supervisor is
invoked only when that flag is present. `test_dispatch_persistent.py` pins the
default path with a faked `Popen`: without the flag it observes exactly one
spawn and no `persistent` or `restart_count` manifest fields.

## Result

The regression criterion holds at the source/test seam: fire-and-forget remains
opt-in and does not enter the supervisor. This experiment does not claim that
every historical argv byte was compared against an archived binary; it is a
focused structural regression check for this round.

Evidence: `extensions/agi/tests/test_dispatch_persistent.py`, especially
`test_fire_and_forget_default_spawns_no_supervisor`.
