### What was run

**HumanEval (164).** `datasets/humaneval-abc/runner.py` run **byte-identical**
against a local shim, `datasets/switch-rule/2026-09-21/proxy.py`, which injects
`Authorization: Bearer $OPENROUTER_API_KEY`, forwards to
`https://openrouter.ai/api/v1/chat/completions`, drops llama.cpp's
`chat_template_kwargs` and adds OpenRouter's `reasoning {"enabled": false}`
(the documented equivalent of the local arms' `enable_thinking: false`), and
logs each response's `usage`. Runner invocation:

```
ABC_OUTDIR=datasets/switch-rule/2026-09-21 \
  <scratch>/venv/bin/python datasets/humaneval-abc/runner.py \
    ref_deepseek-v4.1-flash http://127.0.0.1:8787 deepseek/deepseek-v4.1-flash \
    datasets/switch-rule/2026-09-21
```

Why the shim: the parent asked for `runner.py` to stay byte-identical if
possible, and it does — the only protocol changes are the two documented
translations, in the shim, not the runner. One probe call first confirmed the
model answers with `reasoning_tokens: 0`.

**Scoring (HumanEval).** `datasets/humaneval-abc/scorer.py` run **unchanged**
with `ABC_OUTDIR=datasets/switch-rule/2026-09-21`, tags `ref_deepseek-v4.1-flash`
and the five local stems whose completions are symlinked in from
`datasets/humaneval-abc/` (ABC dir not mutated). Same scorer, same run, so every
per-problem pass/fail map and every discordant `b`/`c` count is computed fresh,
not estimated.

**IFEval (541).** Fresh scratch venv (`pip install absl-py langdetect nltk
immutabledict`) + official sources fetched raw from google-research's
`instruction_following_eval/`. `evaluation_main.py` is the authority and wants
`{"prompt","response"}`. Responses were generated by `ifeval_gen.py` through the
same proxy shim (temp 0, one sample, thinking off, max_tokens 1280) and, because
the run is long, by four shard workers writing resumable `.shard<k>` files that
were merged back into official prompt order. Official harness command:

```
cd <scratch>/ifeval && <scratch>/ifeval_venv/bin/python evaluation_main.py \
  --input_data=<scratch>/input_data.jsonl \
  --input_response_data=datasets/switch-rule/2026-09-21/ref_ifeval_deepseek-v4.1-flash.responses.jsonl \
  --output_dir=datasets/switch-rule/2026-09-21
```
