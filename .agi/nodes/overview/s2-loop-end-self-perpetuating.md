# Season 2 loop end through vision:self-perpetuating -- the cathedral holds only what is in the bytes

## The vision, the question it asks
"This project is a cathedral, what is built today is only meant to be witnessed by generations yet to pass." The graph "points out areas that are obvious gaps and calls out to observers to join the work of completing it."
So the one question for this loop: after the next rotation, the next box move, the next re-render, what does a successor INHERIT -- and does the graph name what it does not yet hold?

## What the three bigger outcomes say together (none says it alone)
```
engine-small-bounded   the zygote can be read whole       -> a successor can LEARN the engine from its bytes
trust-fails-closed     a check that cannot read REFUSES   -> a successor is never told green on nothing
host-holds-truth       truth lived outside the nodes      -> a successor would have LOST it at the next re-render / move
   ─▶ one property across generations: a successor inherits ONLY the bytes; whatever lives elsewhere dies at a boundary
```
Boundaries this loop measured, each one a place where truth died or nearly did:
| boundary | what lived outside the bytes | what the loop did |
|---|---|---|
| a turn end | a commit on a detached HEAD; an edit in ~/t (signal on hook stderr) | goal:g7.16.1.11.38: refuse by name, ~/.notice to the post, box to the master |
| a rotation | a session's own memory of what it ran | cards in nodes; a falsifier result written, not remembered (skill agi-goal) |
| a re-render | host drop-ins 50 / 51 / 52 with no source node | goal:g7.16.1.11.37 F6: engine-root.md names every drop-in; unlisted = RED |
| a box move | 657 refs/archive (only in a pre-move bundle); ~/hooks emptied | 657 restored; goal:g7.16.1.11.39 carries every namespace, box-local refs box-to-box only |
| a close | falsifiers as written but unmet (.13 .19 .34) | one rule: close on the falsifier as written, or amend it with its reason |

## Alignment: ADJUST
The loop did what this vision asks of a loop end: it turned five hidden truths into nodes and five open debts into named leaves (.40 parity, .5.1 fence, .37 drop-ins, .38 strand, .39 refs carry). The graph now points at its own gaps.
It is ADJUST, not aligned, for two reasons:
1. Empathy is violated in the bytes until .38 lands: a post can still lose work without a line it sees.
2. Two of the loop's rules are lines, not checks (close-on-falsifier; host acts land their source). A rule that does not check itself decays within a few generations, exactly like the 10-01 render did.

## What shifts in the vision (one line)
A successor inherits only the bytes: every truth it needs lives in a node, every gap is a named leaf, and every rule carries a check.
