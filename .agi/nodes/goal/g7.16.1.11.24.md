# goal:g7.16.1.11.24

## Why this exists
goal:g7.16.1.11: a post unit gives its shell AGI_SEAT only, while the box piece needs AGI_POST, so the one command a post types by hand to read its mail dies. Checked at trunk 1a63cd6f04: .agi/nodes/.geometry/engine-root.md:28 sets `Environment=... AGI_SEAT=%i` and nothing else of the name (AGI_SEAT is deprecated this season); .agi/nodes/.geometry/engine-post.md:180 starts the box piece with `P=${AGI_POST:?}`, so a hand `box` in any post's shell exits 'parameter not set' (TM 04:0xZ). The two wake pieces already work around it (agi-run, engine-wrap.md:26: `AGI_POST=${AGI_POST:-$AGI_SEAT}`; cccc.ts the same), and engine-wrap.md:91 records the gap as SM mur residue R6, banked there as "a host act, not this leaf": this is that leaf. It is the sibling of goal:g7.16.1.11.23 (belam's session name) in the same unit family, not a widening of it.

## Target end-state
- Every post unit's environment carries `AGI_POST=<instance name>`, the same value as `AGI_SEAT=<instance name>`, so a hand `box`, `box n` and a hand send from any post's own shell find their post without an export.
- The workarounds in agi-run and cccc.ts keep deriving from AGI_SEAT only as a fallback and never run in a pane that already has AGI_POST.
- The unit text is installed on every box by the host act from the pinned commit's bytes, so the change reaches a running post at its next unit start, not before.

## Invariants
- AGI_POST equals AGI_SEAT for one instance: they never differ in a rendered unit.
- AGI_SEAT stays in the Environment= line: other readers still read it and their derivations (`${AGI_POST:-$AGI_SEAT}`) must keep working. Removing it is a separate, later leaf.
- No lane may export AGI_POST itself to get green: a lane that exports it is what hid R6 while every lane was green.

## Falsifier
1. A lane renders the post unit text from the geometry for one instance name and reads both `AGI_SEAT=<name>` and `AGI_POST=<name>` in its Environment= line, then runs `env -i` with only that Environment= line applied and `box n` in the same pane exits without 'parameter not set'; the lane exits 0 only then (it must NOT export AGI_POST by hand).
2. Negative: `git grep -n 'AGI_POST=' -- .agi/nodes/.geometry/engine-root.md` shows no `AGI_POST=` value other than `%i`, and the rendered AGI_SEAT and AGI_POST differ for no instance name.

## Out of scope
Removing AGI_SEAT (its deprecation) · the pure-box cutover (a later leaf, belam's GO) · the host act that re-installs the units on a running box (root, belam's) · goal:g7.16.1.11.23 (the session name).
