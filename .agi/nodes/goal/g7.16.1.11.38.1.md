## Target end-state
- MAIN's repo carries a reference-transaction hook that REFUSES (non-zero, one named line) any update by post uid agi-<p> of refs/heads/posts/<q>, refs/box/<q>/<r>, refs/held/<q>/<r> where q != p (belam, the landing owner, exempt as the council names it); a post's own refs and every other ref behave as today.
- The hook is installed by the same root piece that installs the box's git config (agi-project or its successor), not by hand, and is named in the skill that owns ref writes.
- The leaf says in its own words what it is NOT: `git -c core.hooksPath=/dev/null update-ref ...` still moves a peer's ref (a hook stops MISTAKES, today's case, not intent). The STRONG claim ("no post CAN") needs per-post ref DIRECTORIES (refs/posts/<p>/... owned by agi-<p>, belam rwx) -- a rename of every post's branch -- and is BANKED for the owner, not placed here.
- The lane-side half rides DG4's .37 follow-up (council remark 3, 10:10Z): every lane that `git init`s a scratch repo clears GIT_DIR / GIT_WORK_TREE / GIT_INDEX_FILE first, with a trunk-arg-lanes row RED on a `git init` lane without the clear.

## Invariants
- The hook never refuses a post's update of its OWN refs, nor belam's landings.
- Design fact (aio, measured): a per-FILE ACL cannot do this -- git updates a ref by writing <ref>.lock and RENAMING it, so only the DIRECTORY permission matters (refs/heads/posts is group agi rwx); a file-ACL read of MAIN would be green on a box where any agi uid can still replace the ref, so it is NOT a falsifier.

## Falsifier
1. In a SCRATCH copy carrying the hook (never MAIN): as agi-alive, `git update-ref refs/heads/posts/director-general-1 <sha>` exits non-zero with the named line and the ref is unchanged; as agi-alive, its own posts/alive moves; the hook removed = the first row RED (mutant).
2. Negative / honesty row: in the same scratch copy, `git -c core.hooksPath=/dev/null update-ref refs/heads/posts/director-general-1 <sha>` STILL moves the ref -- the row passes only when the bypass works, so nobody reads the hook as a wall.
