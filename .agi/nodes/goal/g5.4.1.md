## Why this exists
goal:g5.4 (the season review and rollover, end to end): the season-2 -> 3 rollover report was built by hand at the end of the run (belam 10-15, published as the claude.ai artifact FpDnKNzsTQFP4ug5sit9kt, "Season 3 rollover"). ## Target end-state
- ONE template node holds the report's HTML shape. Every derivable section is a slot filled from the graph or git at render time: branch heads and archives, node and edge counts, broken links, evidence fraction, grid ref counts, node-type bars, the rollover timeline from the run's records, goals closed and carried.
- The season rollover skill / scripts render it for the season just closed with one command; a second run on the same refs gives byte-equal derived sections.
- Generative parts (the summary prose, an optional song or voice) are named slots, the only ones a model writes; the page renders correctly with them empty.

## Invariants
- No number in the rendered page is typed by hand; each comes from a command the template names.
- No spend on a provider or scale the owner did not name; the generative slots stay optional.
- Retire, never delete: each season's rendered report is kept, never overwritten by the next.
