- New writes that carry an absolute box path get a WARN (never a refusal, never a sweep of old nodes).

## Invariants
- No test, node, commit message or dm carries a real pre-rewrite id or an old -> new pair: every row uses a SYNTHETIC map in a tmp dir.
- The map file is never tracked and never copied.
