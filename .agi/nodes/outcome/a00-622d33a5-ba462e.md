## Outcome

Input shape (what enters):

- One JSON object, a JSON array of objects, or JSONL containing at least one object record.
- Required on first creation: scalar `session_id` (or `id`) and `goal` (or `goal_id`) resolving to a live `goal:` node.
- Optional provenance: `edited_by` (or `actor`), `thought_session`, and `seat`.

Output shape (what exits):

- On success, stdout is one stable node id: `doc:session-<readable-id>-<sha256-prefix>`; exit status is 0.
- The graph receives one `doc` node with a real mint id, canonical session identity, the JSON records in its body, and the resolved live goal as parent.
- On refusal, stdout is empty, stderr begins `ERR: refusing session artifact:`, and exit status is 2.

Behavior (what it does):

- Canonical identity includes the scalar type and exact value plus a full SHA-256 digest. Thus `A.B` and `A-B` stay distinct even though their readable slugs both normalize to `a-b`.
- A later record for the same exact identity updates that one node through `node_writer.update_node`; it does not mint another id. Omitted goal and provenance are read from the existing node, while the checkpoint body is replaced and the authored THOUGHT region remains writer-protected.
- Creation goes through `node_writer.write_node`, which assigns the permanent mint id once. The returned writer status must be `written`, `updated`, or `unchanged`; any refusal is surfaced rather than treated as success.
- No-goal, unresolved/non-live goal, unsafe identity, traversal goal, malformed JSON, and empty input all refuse by name before a session node is written.

Edge cases:

- Empty or whitespace-only artifacts report `empty session artifact`.
- Missing identity reports `session artifact has no session_id`; non-scalar, blank, path-bearing, whitespace-bearing, or YAML-breaking identities are rejected.
- A missing/unresolved/non-live goal reports its corresponding goal failure. A goal such as `../../../outside` cannot create or select a node outside the graph.
- Non-object records are ignored. If no objects remain, ingest refuses with `session artifact has no records`.
- The ingest reads the first object record for identity, goal, and provenance while retaining all object records in the transcript body.
