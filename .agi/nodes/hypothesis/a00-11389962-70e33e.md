records the live render path actually holds. `load_existing_nodes()` returns

value as a flat frontmatter dict, so on `--render --strict-goals` it returned
`[]` for any tree while the flat-dict unit tests stayed green — an inert guard
exactly where it is meant to fire.

**Claim:** teaching the guard to accept **both** shapes makes it warn on the
live path, with the existing flat-dict callers in
`test_lifecycle_guards.py` still passing unchanged.

**Would prove it:** a wrapper-shaped complete-root/live-child pair produces the
offender triple and the `goal:s26` warning; a flat pair produces the same;
the live `load_existing_nodes()` shape (proved to be wrapper) reaches the
warning.

**Would disprove it:** the wrapper probe still returns `[]`, or fixing the
wrapper shape breaks the flat-dict callers, or the guard fires on a genuinely
finished tree.
