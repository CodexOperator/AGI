## Hypothesis

`rotate.cmd_spawn`, the config:seats row's `window` cell equals the live tmux
@id for that seat, and a seat start that did not land a live pane claims no
window. A single read-only helper (`seat_status.pane_coherent`) lets formation
and pin readers see the live holder without ad-hoc pane scrapes.

window only AFTER launch writes `window == "@7"` on the row; the negative
control (no matching window) leaves `window` empty; `pane_coherent` returns
True on a match, names drift by seat otherwise, and fails open without tmux.

predecessor's stale pid/session_ref.
