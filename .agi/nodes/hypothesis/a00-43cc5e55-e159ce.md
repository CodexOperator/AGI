# hypothesis:a00-43cc5e55-e159ce

## Hypothesis

`write.py` must validate a node's `profile_ref` **before** it writes the node
body, so a refused link leaves the node byte-for-byte unchanged and exits
non-zero. On the inherited order the node body landed first and only the
post-write `sync_node` refused (rc=2) — a caller saw failure while the node
had already changed on disk.

**Would prove it:** a node carrying `profile_ref: ../escape.md` (or
`.agi/nodes/evil.md`), edited through the real `write.py <node> 'note x'`,
returns rc=2 AND its file bytes are identical before and after.
**Would disprove it:** the node bytes differ after a refused edit, or the
command exits 0.

`node_writer.update_node`. `NoRef`/missing node is a no-op; `Refused` raises
