## Hypothesis

A single transport-choice seam (`extensions/agi/bin/messaging.py`) can make
`goal:g7.32.2`'s three falsifier conjuncts measurably true on the returned
values / wire bytes, without re-speccing the pane hold (`g7.31.1`), the five
routes (`g7.31.3`), the pane methods (`g7.32.3`), or `send.py` internals
(`g7.32.4`).

## Testable claim (the three conjuncts)

1. **Native** — same harness (`route(src,dst) == "native"`): `send_native`
   calls the injectable pane seam and NEVER invokes `send.py` transport
   (a spy on `subprocess.run` records zero calls).
2. **Cross** — different harness (`route == "nudge"`): `send_cross` writes
   the nudge artifact file FIRST, then shells `send.py`, and returns ONE
   trace dict carrying BOTH the artifact path and the exact send.py
   argv/return code.
3. **No internals** — `messaging.py` imports no `rotate`/`dispatch` symbols
   (AST import scan + source grep).

## What would disprove it

- A same-harness send that shells out (conjunct 1 fails).
- A cross-harness send with no artifact on disk, or with the artifact and
  the transport invocation split across two traces (conjunct 2 fails).
- Any `import rotate` / `import dispatch` (or `from …`) in the module
  source (conjunct 3 fails).
