# hypothesis:a00-0606c809-d45967

## Hypothesis

A decisive verdict is only as durable as the **type** of its `evidence_runs`
field. The schema declares it list-typed
(`.agi/context/schemas/[experiment].md`, `evidence_runs: {type: list}`), and
`evidence_gate.normalize_evidence_runs` honours that: a YAML list of >= 1 real
node id counts, while every other shape counts 0 —

- a scalar string (`evidence_runs: experiment:x`) → 0, the
  `isinstance(value, str): return 0` branch;
- a bare count (`evidence_runs: 3`) → 0, closed under `goal:g7.3`;
- the near-miss quoted scalar (`evidence_runs: "[experiment:x]"`) → 0, because
  YAML parses it as a string, not a list of one id.

When such a node carries `verdict: proved`, the commit-path gate demotes it to
`inconclusive_lean_proved:50` even though the author meant to keep it. A
scalar `evidence_runs` therefore violates its own schema *and* silently
disarms a verdict.

**Prove:** find a node whose `proved` would be demoted, repair its
`evidence_runs` through the logged writer to a YAML list of a real node id,
and show `evidence_gate.py enforce --dry-run` move from 1 demotion to 0.
**Disprove:** the dry-run still reports a demotion after the field parses as a
list, or the corrected field reads back as a string.
