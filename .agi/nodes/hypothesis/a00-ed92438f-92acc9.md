# hypothesis:a00-ed92438f-92acc9

## Hypothesis

A grok session artifact can be ingested into this tip's graph as a real,
linked node — **on demand and in batch** — by one script that writes through
the sanctioned `node_writer`, is idempotent by `source_session` (mint ids are
random, so the session key is the only key), refuses malformed/empty input and
missing provenance BY NAME with rc=2 and no write, and scans a directory in
stable sorted order without letting one bad artifact abort the batch.

## Falsifiers (all run at the CLI on a throwaway graph root)

1. One fixture JSONL → a real `hypothesis:grok-...` id on stdout AND exactly
   one new `.md` under `<root>/nodes/`.
2. Re-running the same command → the SAME id, no second file, `mint_id`
   unchanged.
3. `{not json` → `refused: ...`, rc=2, no file.
4. Empty input → `refused: empty session artifact`, rc=2, no file.
5. No `--actor`/`--thought-session` and no `AGI_ACTOR`/`AGI_AGENT_ID`/
   `AGI_THOUGHT_SESSION` → `refused: no actor`, rc=2, no file (never a silent
   anonymous write).
6. `--scan DIR` over {good, good, malformed} → ids in sorted order, the
   refusal printed, rc=0, and a second scan prints the same ids with no new
   files.

What would disprove it: any step writing two nodes, writing on a refusal,
returning a different id on re-run, aborting the batch on one bad artifact, or
minting without `edited_by`/`thought_session`.

## Result

**Proved on the bytes built on this tip.** The five falsifiers and the batch
scan all hold; 9 tests pass. Evidence and raw stdout live in
