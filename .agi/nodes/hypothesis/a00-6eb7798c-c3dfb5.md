## Hypothesis

If `--persistent` is omitted, dispatch must retain the default fire-and-forget
behavior and resolved launch bytes; adding the flag may alter lifecycle and
record fields, but must not alter the production argv or environment.

## Falsifiable test

Run the real `dispatch.main()` path twice against a scratch project, capture
its detached Popen argv/env, scrub only random agent/node identifiers and the
persistent stop control, and compare. Then assert the default manifest lacks
`persistent` while the persistent manifest contains it. The default and
persistent lifecycle tests must also remain green.
