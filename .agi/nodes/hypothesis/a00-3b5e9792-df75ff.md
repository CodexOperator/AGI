## Claim

The `send` verb's transport choice (room / dm / inbox) can come from a
module-level table in a new stdlib-only `bin/send_router.py`, so a new transport
is a `register()` row plus a module — never another `if` in `send.py` — and
`send.py` can call that table at its live call site without changing behaviour.

Proved by: (thin) an AST check showing the router imports no
rotate/dispatch/send/seatsig; (extensible) registering a fresh stub transport
returning it from `choose()` with no module edit; (wire) `main(["send","--room",
"r","hello"])` reaching `send_router.choose` live.
