# hypothesis:a00-1b1989e4-66b3ba

## Hypothesis

A durable named-tmux hold adapter can preserve named-pane startup and reattach while guaranteeing an explicit direct `subprocess.Popen` fallback whenever the durable session/pane is unset or tmux is unavailable. The adapter must have a real build payload record, not merely an untracked helper file.

**Proved by:** focused fixture tests for both fallback states, the existing-pane `attach-session` path, and the new-pane detached start path, plus a build node whose `payload_ref` names the source.

**Disproved by:** either fallback state returns without invoking `Popen`, a present named pane does not reattach, or no build/grid record covers the adapter.

## Agent Notes
Built and grid-covered tmux_hold; explicit Popen fallback and named-pane paths pass 4 focused tests.
