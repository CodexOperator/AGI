# hypothesis:a00-d5316b51-a1627c

## Hypothesis

`profile_sync.check_all`'s unreadable heuristic must be scoped to the
frontmatter region, not the whole file, and its unreadable-file path must
never raise. A malformed node whose BODY merely says `profile_ref:` is not
profile-linked and must be a clean no-op; only a `profile_ref:` inside the
frontmatter region (where YAML itself failed) may be named `unreadable`.

## What was built

Two edits to `extensions/agi/bin/profile_sync.py` (20 added / 6 removed
lines, ceiling 40):

1. **Frontmatter-scoped hint.** The except branch now calls the shared
   boundary reader `frontmatter.split_frontmatter(raw)` (the one
   `_FM_LINE`-anchored splitter in `extensions/agi/bin/frontmatter.py`)
   instead of scanning the whole file. No parseable frontmatter region ->
   skip (P7: not ours to fail). Hint only in the body -> skip.
   Hint inside the frontmatter region -> `unreadable` as before.
   `_raw_profile_ref` is fed that same region, so a body mention can never
   name the artifact of an unrelated file.
2. **Guarded read.** The `f.read_text(...)` call is wrapped: an
   `OSError`/`PermissionError` yields a named `unreadable` row whose detail
   carries the exception, so `check_all` never raises and
   `rotate._check_profile_drift` sees a clean sweep or named rows.

## Evidence

Pre-fix probe (`check_all` on a malformed node with `profile_ref:` only in
the body): `[('broken', 'unreadable')]` — a body word forced rc=1.
Post-fix: `[]` for body-mention, `[('broken','unreadable','profile/b.md')]`
for a frontmatter link, `[]` for no frontmatter.

Three tests added to `extensions/agi/tests/test_profile_sync.py`; the two
discriminating ones FAIL on the pre-fix bytes (verified by temporarily
restoring the whole-file scan):

- `test_body_only_profile_ref_mention_is_not_unreadable` — clean no-op,
  `--all` rc=0, guard None. FAILS pre-fix.
- `test_read_text_failure_yields_a_named_row_not_a_raise` — monkeypatched
  `Path.read_text` raising `PermissionError`; `check_all` returns a named
  row and never raises. FAILS pre-fix.
- `test_frontmatter_profile_ref_is_still_named_unreadable` — P8 not
  regressed.

`python3 -m pytest extensions/agi/tests/test_profile_sync.py -q` -> 22
passed. This file is the only test file referencing `profile_sync` /
`_check_profile_drift`.
