# hypothesis:a00-e9e22ed7-63f7a7

## Hypothesis

A grok-bot seat holds ONE durable, named tmux pane from its FIRST spawn
(`goal:g7.31.1.2`). Killing the seat's process and calling `restart`
re-enters the SAME pane: the immutable `#{pane_id}` is unchanged, a second
seat window is never fabricated, and the recorded
`agent_record["tmux"]["created"]` is `False`. If the pane is genuinely gone
(the window, not just the process, was killed) `restart` recreates it ONCE
and records `created: True`.

The hold is declared by the adapter itself (`HOLD_PANE` + `hold_harness()`),
not by a harness-string branch in `dispatch.py`; the FIRST-SPAWN path asks the
adapter to seat the process, so the pane exists BEFORE the process and before
any restart — a hold that begins at restart is not a hold.

**Falsifiers:** (1) first spawn leaves no seat window in the session;
(2) restart after a killed process reports `created: True` or returns a
different `#{pane_id}`; (3) `restart` of a genuinely gone pane leaves two seat
windows; (4) `panes()` cannot see a non-current window (missing `-s`);
(5) a `grok` special-case appears in `dispatch.py`.

Evidence: `experiment:tmux-pane-hold-first-spawn` — real tmux 3.4 on a scratch
session (`agi-dt67-probe-<pid>`, never the live `agi-rc`), plus FakeTmux
fixtures for the non-current-window and genuinely-gone-pane cases.

## Agent Notes
Built durable named tmux pane hold: adapter-declared HOLD_PANE/hold_harness, tmux_hold.py (first-spawn spawn(), pane-id reattach, -s list-panes), dispatch _open_round seats the process in the pane with no grok special-case. Real-tmux proof: first spawn founds the seat window; killing the process and restart returns the SAME #{pane_id} with created False; a killed window recreates once with created True. 9/9 test_tmux_hold, 63 adapter/restart, 43 dispatch tests pass.
