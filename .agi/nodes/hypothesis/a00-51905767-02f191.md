# hypothesis:a00-51905767-02f191

## Testable claim

A completed grok session artifact can land as **one graph node** via one
command, idempotently: the same artifact bytes resolve to the same
deterministic slug, hence the same `node_id`, so a second ingest returns
`SKIPPED` with the `mint_id` byte-identical; a malformed / empty / missing
artifact is refused **by name** (non-zero exit, reason on stderr, no node);
and `edited_by` / `thought_session` are carried from the artifact.

Disproved by: a second run minting a new `mint_id` or a second file; a bad
artifact exiting 0 or leaving a node; provenance absent or wrong.

## Why `hypothesis` and not `idea`

The goal-parentable set is `{hypothesis, idea}` (`experiment` cannot hang
under a goal — `[experiment].md` removed `goal` on 2026-09-01). `hypothesis`
is chosen because a session's distilled summary is carry-forward residue of an
existing chain, which is what a hypothesis is; `idea` is a seed for a **new**
chain and additionally requires `scale`. Both are legal here; this is the
documented choice.

## Build

`extensions/agi/bin/ingest_session.py` — 80 production lines (ceiling 40; at
2x, not above, so no rebrief). Written through the one writer,
`node_writer.write_node(root, type, slug, parents, extra_fm, body,
announce=False)`, with the default `on_exists=SKIP`.

```
python3 extensions/agi/bin/ingest_session.py <artifact> \
    --parent <node-id> [--root <graph-root>] [--type <node-type>]
```

- **Idempotency is derived, not stored:** slug =
  `grok-session-<session_id>-<sha256(artifact bytes)[:12]>`. `mint_permanent_id()`
  is random, so stability cannot come from it; it comes from the deterministic
  slug resolving to an existing file, at which point `write_node` returns
  `SKIPPED` before minting. Two different sessions never collide; the same
  bytes are stable.
- **Type:** `--type` wins; else derived from the parent's resolved type via
  `CHILD_OF = {goal→hypothesis, idea→hypothesis, hypothesis→experiment}`;
  default `hypothesis`.
- **Refusal precedes every write:** `load_artifact` runs before `write_node`;
  `refused: <reason>` on stderr, exit 2, no file.
- **Provenance:** `edited_by` ← artifact `agent_id`, `thought_session` ←
  artifact `thought_session`; plus `title` and `testable_claim` (the summary).
- `--root` defaults to `locations.find_project_root()`.
