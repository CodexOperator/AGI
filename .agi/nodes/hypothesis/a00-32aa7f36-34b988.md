## Claim

`extensions/agi/bin/messaging.py` implements the cross-harness path
(`goal:g7.32.2` falsifier conjunct 2): for a target whose harness differs from
the sender's, `cross_send` emits the **pane-intent nudge artifact first**, then
invokes the existing `send.py` transport (`send.send_dm`) — both events in ONE
ordered trace, in that order. It never calls `native_send`, never types the
message body with `tmux send-keys`, and the module still imports neither
`rotate` nor `dispatch`. The nudge is *recorded*, not typed: `send_dm` already
fires its own pane wake, so the body is never duplicated natively.

Falsified by: a `cross_send` trace whose order is not `nudge → send_dm`, a
`cross_send` that reaches `native_send`, body keystrokes, or a transport call
that never happens.

## Built (diff on top of kid 1's 40 lines)

- `_pane_intent(root, to_seat, *, tmux_session=None) -> dict` — `messaging.py`
  L39. Resolves the recipient's `@id` window via the existing read-only
  `_native_target`; on `NoAddressableWindow` records `pane=None` instead of
  refusing (a windowless seat is still deliverable through the dm file). Types
  NOTHING. Returns `{"event": "nudge", "to", "pane", "via":
  "send.py _nudge_window"}`.
- `cross_send(root, to_seat, text, *, sender=None, tmux_session=None) -> dict` —
  `messaging.py` L56. Order is: `_pane_intent` → `send.send_dm(root, sender or
  "unknown", to_seat, text, sender)`. Returns
  `{"path": "nudge-send", "nudge": …, "transport": {"event": "send_dm",
  "dm": …}, "events": ["nudge", "send_dm"]}`.

`send_dm` is imported **inside** `cross_send`, so a test that monkeypatches
`send.send_dm` sees the patch (same module object); a `from send import
send_dm` would have silently bypassed it.

```

     route() == "native"                   route() == "nudge-send"
            │                                      │

   native_send(root,to,text)              _pane_intent(root,to)
   ├─ _native_target  (read rows)         ├─ _native_target (read rows)
   │    row.window @id                    │    record WHERE the wake lands
   │                                       │    (pane=None if no @id window)

   └─ tmux send-keys Enter                ▼   events = ["nudge"]
```

The nudge token is **send.py's own** wake: cross_send records the pane-intent
and lets the transport fire it, so one body => one pane line, never two.
