# hypothesis:a00-557ad6f2-2234c5

## Hypothesis

Both live residues of the graph->profile projection (`goal:g7.31.5.1`) can be
closed in production bytes without introducing a second source of truth:

1. **Partial write.** `write.py <node with a bad effective profile_ref>`
   refuses BEFORE `node_writer.update_node`, so the node body is byte-identical
   before and after, rc is non-zero, and a named refusal (`profile projection
   refused: profile_ref ...`) says the ref is at fault, with no traceback.
   The *effective* ref is the POST-EDIT one: an edit that unsets a bad ref or
   replaces it with a valid one MUST still land (no deadlock); one that leaves
   a bad ref untouched refuses.
2. **Missing node.** `profile_sync.py <nonexistent-node>` prints a named
   refusal and exits 2 instead of an uncaught `FileNotFoundError` traceback;
   no artifact is created.

Preserved invariants: no-ref rc=0 no-op; `--check` drift rc=1 without
writing; same-action projection on `replace body`; outside-repo, `.agi/nodes/`,
and directory refs refused by name; no `.tmp` left on any refusal path; the
graph stays SoT and the artifact stays a projection; `write.py` still performs
no direct file write (its AST guard stays green).

## What would disprove it

The node body changing on a refused write; a bad-ref deadlock (cannot
unset/replace the ref); a traceback surviving the missing-node path; or any
previously-passing conjunct regressing.

## Implementation

- `profile_sync.project()`: `FileNotFoundError(node_id)` ->
  `Refused(f"node {node_id!r} not found")`; `main()` already maps `Refused`
  to a `REFUSED:` line and rc=2.
- New `profile_sync.validate_effective(root, node_id, set_fm, unset_fm)`:
  read-only; computes the post-edit ref (set_fm wins, then unset_fm clears,
  else the on-disk value) and calls `artifact_path()` on it when non-empty.
- `write.py submit()` calls it immediately before `node_writer.update_node`,
  wrapping `Refused` in `EditError`. The existing post-write `sync_node` call
  is unchanged.

Production diff: 23 added / 1 removed in `profile_sync.py`, 11 added in
`write.py` = 34 lines against a 40-line ceiling.
