# hypothesis:a00-c31f0084-6ccd42

## Hypothesis

A completed or checkpointed Grok session can be ingested through one deterministic, idempotent command that preserves actor provenance and emits a graph-addressable node (or an explicit refusal), without requiring a hand-copied note.

## Testable claim

The existing agent-facing engine exposes a session-ingest entrypoint that accepts a session artifact, creates at least one node under `.agi/nodes/`, records the actor/session provenance, and re-running the same artifact does not create a second mint identity. The claim is supported by a source audit if such an entrypoint and its idempotency marker are present; it is falsified if no entrypoint exists or the available writers mint unconditionally.

## Boundary

This is an audit of the current engine surface, not a new implementation. The next step can build the smallest adapter around the discovered writer once the contract is named.
