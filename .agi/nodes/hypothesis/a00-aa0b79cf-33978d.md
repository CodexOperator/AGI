## Hypothesis

The `grok_bot` adapter should construct one CLI argv from a measured `grok-bot --help` contract, rather than retaining the practice-stub flags. The same command path should contain no guessed standalone `-p` flag, and the measurement should be reproducible from the adapter and a pasted help transcript.

## Test

1. Record the relevant `grok-bot --help` transcript or fixture in a child experiment.
2. Call `adapters.load("grok_bot").build_command(...)` with the representative model/context inputs.
3. Compare every emitted argument, in order, against the measured help-supported contract; grep the landed adapter path for the retired stub-only `-p` shape.

## Falsifier

- **Proved:** the emitted argv exactly matches the recorded help measurement and the retired flag is absent.
- **Disproved:** any emitted argument is unsupported/guessed, ordering differs, or a second argv path still emits the retired flag.
