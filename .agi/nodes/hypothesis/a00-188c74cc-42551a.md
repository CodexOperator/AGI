# hypothesis:a00-188c74cc-42551a

## Hypothesis

`extensions/agi/bin/magic_pane.py` is the magic-pane messaging seam with
exactly two routes, and the route is chosen from the DESTINATION harness
**family** — with the registry/adapter name -> family map held as **data**
(`HARNESS_FAMILIES`), never an `if harness == "grok-bot"` soup. Round 1 keyed
`NATIVE_HARNESSES` on the invented string `"grok"`, which no live caller ever
constructs (the tree's only grok name is the registry/adapter name
`grok-bot`), so the native route was unreachable through the live registry —
the exact defect this round repairs.

- **NATIVE (same family, e.g. grok-bot -> grok-bot):** `send_message` types the
  message directly into the destination seat's tmux pane (literal
  `send-keys -l`, pause, a separate `Enter`). This route never invokes
  `send.py` — not even as a fallback when tmux returns non-zero — and does not
  import it.
- **CROSS (grok-bot -> claude-code / pi):** `send_message` FIRST writes a
  `.nudge` artifact, THEN invokes `send.py send`. The artifact is resolved
  through `send.comms_root` (send.py's own reader), so nudge and message share
  one room rather than a parallel fork.

### Testable claim (three conjuncts, on LIVE names)

1. **NATIVE, on the names the tree actually builds.** With a faked tmux,
   `grok-bot -> grok-bot` produces exactly the two `tmux send-keys` argv and
   no captured argv contains `send.py`; a non-zero tmux return keeps the route
   native and still never reaches `send.py`.
2. **CROSS, ordered, in send's room.** With a faked send.py seam,
   `grok-bot -> claude-code` and `grok-bot -> pi` write the nudge artifact
   (under `send.comms_root(root)/pane-nudge/`) AND the captured argv contains
   the send.py invocation — one trace, artifact on disk BEFORE the subprocess
   launches.
3. **IMPORT GRAPH.** After `import magic_pane`, `rotate` / `dispatch` (and
   `send`) are not in `sys.modules`; the module source has no such import at
   module level (`send` is imported lazily, on the cross path only).

### Disproof

Any conjunct failing: `choose_route("grok-bot") != "native"`; a native argv
smuggling `send.py` (including on the rc!=0 path); an artifact absent at (or
written after) the send.py call; an artifact outside `send.comms_root`; a
transitive rotate/dispatch/send import from merely importing the module.
