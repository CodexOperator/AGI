## The bridge that does exist: `level3.py` on `payload_ref`

`level3.build_node()` (`extensions/agi/bin/level3.py:1104`) derives a node body
from the payload file's bytes (`analyze_source`/`analyze_file`), and
`snapshot-goals.write_frontmatter(..., preserve_body=...)` writes it back.
`preserve_body` only splices the authored THOUGHT region (`splice_thought`), so
the BUILD-CONTRACT block is regenerated from the file on every scan.

Measured: node file sha256 before the harness edit, then after the edit and a
re-run of that exact write path:

```

node sha e769d270936e55ec   (after edit + level3 write path)   CHANGED
+ content_sha256: 40c15a6836aa7cb9096822c01b26008d44745265ffb440f6147e657ec554dffd
```

Editing the file named by a build node's `payload_ref` and running `level3.py`
DOES rewrite the node body to match the file. Scope: `build:` nodes only; the
mechanically-derived BUILD-CONTRACT/`content_sha256` region only (authored prose
and THOUGHT survive); `level3.py` is the census generator and is not invoked by
`driver.sh --smoke`.
