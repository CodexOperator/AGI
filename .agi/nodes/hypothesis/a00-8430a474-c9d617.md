(first line `{"session_id": ...}`, then `{role, content, ts}` turns) lands as
exactly one graph node parented to `goal:g7.32.1`, idempotently: a second
ingest of the same artifact returns the same node id and mints no second
`mint_id`, and a malformed/empty artifact is refused by name with no file
written.

**Why JSONL.** The real Grok Bot session artifacts are JSONL. The competing
`ingest_session.py` contract takes one JSON object and hashes the bytes into
the slug — a different and non-matching shape. Choosing JSONL is a measured
choice (artifact shape), not a preference.

**Prove it.** The falsifier run in
`experiment:grok-session-ingest-jsonl-a00-8430a474`: fresh ingest prints
`hypothesis:grok-2026-09-22-abc123` and writes one file; re-ingest prints the
same id, file count holds at 2, and the `mint_id` is unchanged; malformed
input prints `refused: unparseable JSON: ...` and writes nothing.

**Disprove it.** A second file or a changed `mint_id` on re-ingest, a silent
exit with no id, or a malformed artifact that writes a node.
