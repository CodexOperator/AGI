# hypothesis:a00-3d3be177-3bca48

## Hypothesis

A `write.py` write to a node whose (resolved, post-edit) `profile_ref` is
REFUSED must refuse BEFORE the node body lands: exit 2, the named
`profile projection refused: …`, and zero bytes changed. On the base it
refuses AFTER `node_writer.update_node`, so a refused action silently advances
the graph — the "skipped silently" shape `goal:g7.31.5.1` forbids.

The ref that matters is the one the node WILL have: this edit's `set_fm` wins,
`unset_fm` removes it, absent means the value already on disk.

### Testable claim (conjuncts)

1. `<linked-node> 'replace body …'` with a refused existing ref — for each of
   {outside repo root, under `.agi/nodes/`, a directory} — exits rc=2 with the
   named refusal AND the node file sha256 is unchanged.
2. `<node> 'set profile_ref <refused-value>'` (the edit sets the bad ref) also
   refuses before any node bytes change.
3. Happy path unregressed: a valid ref still lands the body and moves the
   artifact to the normalized new body in the same action.
4. `write.py` ast guard (`test_write.py::test_edit_py_contains_no_file_write`)
   stays green — no direct file write in `write.py`.

### What would disprove it

A refused `profile_ref` write that still leaves the node body advanced (sha
changed); a green suite only because no test calls the refused write path; the
happy-path artifact no longer matching the body; a new direct file write in
`write.py`.

## Build

- `profile_sync.validate_ref(root, ref)` (11 production lines): resolve-only
  pre-flight; delegates to `artifact_path`, raises `Refused`, writes nothing.
- `write._preflight_profile_ref(root, edit)` called in `submit()` immediately
  before `node_writer.update_node` (hence before the payload write too). It
  reads the effective post-edit ref; an `unset_fm` drops it and a node with no
  ref is a no-op.
- Production lines: 42 (`write.py` 31 + `profile_sync.py` 11), against a
  ceiling of 40 — 2 over, well under 2x, so no re-brief is required.

Proved on the built bytes: the refusal is non-partial for all three refused
ref classes and for a ref the edit itself sets, at 42 production lines, with
the happy path and the ast guard green.
