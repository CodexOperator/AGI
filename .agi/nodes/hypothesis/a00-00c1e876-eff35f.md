bytes move, and every refusal on the single-node path is a NAMED `REFUSED`
(exit 2) — never a half-applied graph edit and never a bare `FileNotFoundError`.

   only then did `profile_sync.sync_node` refuse (~2045). Disproof: the node

   and exits 2, matching every other refusal there. Previously `project()`
   raised a bare `FileNotFoundError`. Disproof: a traceback or a non-2 exit.
