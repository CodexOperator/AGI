# hypothesis:a00-1f1994dd-051a0b

## Hypothesis

The magic-pane messaging seam can be a thin adapter (`extensions/agi/bin/messaging.py`)
whose harness comparison alone selects the transport: same harness → native pane
`type` with no `send.py` in the path; different harness → `nudge.write` (pane intent)
first, then the real `send.py` (transport), in that order. An unknown/empty harness
refuses by name (`UnknownHarness`) instead of defaulting, and the module imports no
`rotate`/`dispatch` internals.

**Prove it:** `native_send` types exactly `(to, text)` and never reaches `send.py`;
`cross_harness_send` bound to the real `send.send` into a temp root produces a nudge
artifact and then the real inbox block, with `steps == events == [nudge.write,
send.send]`; a source grep finds no `rotate`/`dispatch` import.

**Disprove it:** same-harness reaches `send.py`; cross-harness records `send.send`
before `nudge.write` or skips the nudge; an empty harness routes instead of raising.

**Result:** proved by `experiment:a00-messaging-seam-r3` — 21/21 tests green,
measured trace pasted in that node. The adapter is 39 production lines.
