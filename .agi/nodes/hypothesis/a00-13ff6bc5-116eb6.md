## Hypothesis

A hold restart can satisfy the seat's durable-startup contract without requiring tmux: when the tmux executable is unavailable or the configured session does not exist, the same restart seam should select one direct `Popen` child and return its handle instead of failing or attempting a tmux attachment. The fallback should preserve the prepared child environment, while successful tmux reattachment should remain the preferred path.

## Discriminating test

With `tmux_hold` imported behind injected fakes, exercise restart once with the executable probe failing and once with the named session absent. Assert each case performs exactly one direct spawn, never calls tmux send/attach, and passes the already-computed child environment. Also assert that, when both the executable and session are available, no fallback spawn occurs and the existing reattach result is returned unchanged.

**Proved if:** all three cases satisfy those branch-specific assertions.  
**Disproved if:** an unavailable prerequisite reaches a tmux command, raises before spawning, spawns more than once, or returns a child with environment differing from the normal Popen restart path. Grid payload coverage is a separate accounting check, not evidence for this behavioral claim.
