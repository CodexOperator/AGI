## Hypothesis

`extensions/agi/bin/ingest_session.py` refuses every malformed artifact **by
name, with a non-zero exit and no traceback**, including the shape the parent
probe used to falsify the prior round: readable JSON that is not an object.

**Would prove it:** a non-object artifact (JSON array, `null`, or scalar) fed
to the built CLI prints `REFUSED <path>: expected a JSON object, got <type>` on
stderr, exits 2, writes no node file, and the same holds for an arbitrary
`--root` that is not a graph root; while all previously-passing behaviour
(wire, idempotent re-run on `ingest_key`, provenance, missing-field refusal)
still passes `pytest extensions/agi/tests/test_ingest_session.py`.

**Would disprove it:** any non-object shape raises (traceback / `AttributeError`
from `.get`), or exits 0, or mints a file; or any inherited test regresses.

## Boundary

The fix branches on `isinstance(art, dict)` before `art.get`, so all non-object
shapes share one guard. `--root` is accepted when it holds an existing `nodes/`
dir or a resolvable config — an empty directory, even one named `.agi`, is
refused. `key_of` and the `ingest_key` frontmatter contract are deliberately
untouched. The artifact remains synthetic: no Grok transcript exists on this
box, so this proves the pipe, not Grok field mapping.
