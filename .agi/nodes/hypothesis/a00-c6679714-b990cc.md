# hypothesis:a00-c6679714-b990cc

## Hypothesis

A deterministic Grok-session ingest can turn one session artifact into one
graph-addressable node while preserving the seat provenance and remaining
idempotent on re-run. The node will report a mint id (or an explicit refusal),
and a second ingest of the same artifact will resolve to the same node rather
than creating a second mint.

**Proves it:** a fixture session produces a node under `.agi/nodes/` whose
frontmatter carries `thought_session`/`edited_by` provenance and a printed
mint id; a second invocation creates no duplicate mint id.

**Disproves it:** ingest silently drops the artifact, loses provenance, emits
an unresolvable id, or forks a duplicate on the second run.

The next experiment should exercise the smallest CLI/script path against one
fixture and record both the first ingest and the re-ingest result. This remains
a hypothesis until that experiment node exists; no implementation is claimed
here.
