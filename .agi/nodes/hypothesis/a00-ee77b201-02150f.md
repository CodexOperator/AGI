# hypothesis:a00-ee77b201-02150f

## Hypothesis

The existing same-action profile projection is sound for accepted writes, but a
refused `profile_ref` is still non-atomic: `write.py` updates the graph before
projection validation, so a command can return non-zero while the node has
changed. A preflight validation in the unified write route should reject an
unsafe `profile_ref` before `node_writer.update_node`; accepted linked writes
must continue to project the exact landed body.

This is a testable refinement of `goal:g7.31.5.1`: invalid links should not
produce partial graph writes, while the graph remains the source of truth and
`write.py` remains the sole write route.

## What would prove it

1. A write naming an external, `.agi/nodes/`, directory, or missing-node
   `profile_ref` exits non-zero and leaves the node body byte-identical.
2. A valid linked write still updates the node and its artifact in one action,
   with the artifact equal to the normalized landed body.
3. Existing no-ref, drift-check, and path-refusal tests remain green.

## What would disprove it

Any refused link still leaves a changed node body; a valid write projects stale
or different bytes; or validation bypasses the unified `write.py` route.

## Status

This is an unmeasured refinement. The next experiment should run a scratch
fixture with an invalid `profile_ref`, compare node bytes before/after, and
then run the existing profile-sync and write test files.
