- **write**: a node field is changed by `write.py`, and the title verb is
  what renames the node — no hand-edit of the file.
- **send**: a dm is delivered by `send.py`, which prints the inbox path it
  wrote — no `>>` append.
- **dispatch route**: `workflow.py run ... --dry-run` resolves the real
  manifest, emits one `[dispatch]` line per stage, and names
  `via dispatch.py kids`.
- **authorisation**: a kid's send to a non-parent seat is refused, by name,
  with a non-zero exit.

## What is NOT proven

  was spawned and no paid model was called. The wiring from `workflow.py` to
  `dispatch.py` is proven by the printed route and the resolve path, not by
  an observed child process.
- The unknown-workflow gate is **not** the named refusal the brief expects:
  it is an uncaught `FileNotFoundError` with exit 1 instead of a named
  message with exit 2. The gate therefore fails its own stated contract.
- Only `review` was resolved; other workflow manifests were not sampled.
- This node is typed `hypothesis` although the brief asked for an
  `experiment` scaffold — the dispatch scaffold minted the wrong type.
