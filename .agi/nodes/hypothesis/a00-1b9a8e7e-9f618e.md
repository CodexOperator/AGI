# hypothesis:a00-1b9a8e7e-9f618e

## Hypothesis

A node may be LINKED to a projection artifact by a `profile_ref` frontmatter
field (a NEW field, never `link_ref`, which resolves file -> node and would
invert this invariant). `write.py` writes the artifact in the SAME action as
`node_writer.update_node`, by delegating bytes to `profile_sync.sync_node` —
so `write.py` still contains no file write of its own. The artifact is the
node body with frontmatter and the THOUGHT region stripped, normalized to
exactly one trailing newline; the graph remains the source of truth and the
artifact a projection.

## What would prove it

1. `write.py <linked-node> 'replace body ...'` leaves the artifact bytes
   equal to the node's normalized body — one command, no second step.
2. A node with no `profile_ref` is an explicit no-op (no artifact, exit 0).
3. `profile_sync.py <node> --check` exits non-zero on drift and does not
   write; it exits 0 when bytes match.
4. `profile_ref` resolving outside the repo root, or to any path under
   `.agi/nodes/`, is refused by name (exit 2) and nothing is written.

## What would disprove it

The ast guard in `extensions/agi/tests/test_write.py` failing (a direct file
write crept into `write.py`), the artifact drifting from the body after a
write, `--check` writing, or a refusal silently creating a file.
