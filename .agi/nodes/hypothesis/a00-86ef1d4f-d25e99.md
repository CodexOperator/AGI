# Pane hold threads the scrubbed child env and refuses rather than degrading

## Hypothesis

The durable named-pane hold in `grok_bot_adapter.restart(hold_pane=True)` can be
made to honour the same three invariants the direct `Popen` path already does,
without touching `dispatch.py`/`rotate.py` and without changing the default
(`hold_pane=False`) path byte-for-byte:

- **A (auth/wire):** the pane spawn carries the SAME `child_env(...)` the direct
  spawn uses, so `drop_unneeded_credential` is not lost — an
  `OPENROUTER_API_KEY` sentinel must not appear in a `needs_credential=False`
  grok-bot pane's child environment.
- **C (gate):** tmux *present but failing* is a NAMED refusal
  (`PaneHoldError`), never a silent anonymous `Popen`; tmux *absent*
  (`FileNotFoundError`) keeps today's fallback.
- **D (gate):** a successful respawn whose `list-panes` pid read fails raises a
  named partial state, never a bare `None` that reads as "not restarted".

Falsified if a recording shim still shows no env flags, if failing tmux reaches
`Popen`, if the failing-pid case returns `None`, or if kid-1's core hold
regresses.

## What was built

`extensions/agi/bin/adapters/grok_bot_adapter.py` (+36/-10 production lines):

- `PaneHoldError(RuntimeError)` — tmux present and failing.
- `_tmux` returns `None` only for absent (`FileNotFoundError`/`OSError`); a
  `TimeoutExpired` is named.
- `hold_in_pane(..., env=...)` emits `-e NAME=VALUE` pairs **before** `-c`, so
  the command argv stays last and kid-1's shim's `argv.index("-c")+2` slice is
  unchanged. `has-session`/spawn rc != 0 raises; absent returns `False`.
- `restart` passes the already-computed `env` and raises when a successful hold
  yields no readable pid.

Default `hold_pane=False` is untouched.

## probes

Each probe is the negative of its defect, run against the BUILT bytes:

- **wire** — `test_pane_spawn_carries_the_scrubbed_child_env`: shim state
  records `GROK_TEST_MARKER` PRESENT and `OPENROUTER_API_KEY` ABSENT in the
  pane child env. Pre-fix the spawn carried no `-e` at all, so the recorded env
  was `["PATH"]` and the marker assert would fail.
- **gate** — `test_present_but_failing_tmux_is_a_named_refusal`: every tmux call
  rc-1 → `PaneHoldError`, and `output.log` absent proves no anonymous `Popen`
  ran.
- **gate** — `test_failed_list_panes_after_successful_respawn_is_named`:
  respawn succeeds (log count 1), `list-panes` rc-1 → `PaneHoldError`, never
  `None`; the recorded pane pid is still alive, so the hold is genuinely up.
