# hypothesis:a00-6138b588-bdf17f

## Claim

The production `_open_round` closure can found (or re-enter) a pane named from
seat + agent id, record its immutable `pane_id`, and preserve that same id
after SIGKILL, with no typed shell command and no out-of-band starter call.

It is proved by a unit test over the production seam plus a real-tmux run that
kills the pane's process and re-enters by name. It is disproved if SIGKILL
destroys the pane identity, if re-entry creates a second id, or if tmux absence
silently degrades.
