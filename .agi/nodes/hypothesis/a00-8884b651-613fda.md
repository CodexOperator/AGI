# hypothesis:a00-8884b651-613fda

## Hypothesis

A Grok session artifact can be ingested into the graph as an addressable
`agent_session` node through the one gated writer (`node_writer.write_node`),
and re-ingesting the same artifact reuses the same node address and `mint_id`
rather than forking a duplicate.

**Prove it** by building `extensions/agi/bin/ingest_grok_session.py` and showing:

1. a fixture session -> ≥1 node id on stdout and a file under
   `nodes/agent_session/`;
2. a second run of the SAME fixture -> the same node id, one file, one
   `mint_id`;
3. a malformed fixture -> a named refusal, no node written.

**Disprove it** if any of those three fails, or if the ingest path writes node
frontmatter without reaching `node_writer.write_node` (a hand-rolled write is
not this hypothesis).

## Falsifier

- `python3 extensions/agi/bin/ingest_grok_session.py --fixture <fixture>` prints
  `agent_session:<slug>` and creates `.agi/nodes/agent_session/<slug>.md` with
  `parents: [goal:g7.32.1]`, `edited_by` and `thought_session`.
- Re-run: same id, one file, one `mint_id`.
- Malformed fixture: `refused: <named reason>`, no file.
- `python3 -m pytest extensions/agi/tests/test_ingest_grok_session.py -q` green.

## Activation note

`agent_session` was an inactive schema (`active: false`, zero nodes). It was
activated by writing `.agi/context/schemas/[agent_session].md` (bracketed =
