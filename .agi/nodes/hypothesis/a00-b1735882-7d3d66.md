## Hypothesis

**Testable claim.** The cold-seat brief / custom-instruction surfaces at this
  tip each carry one line naming all five pane-facing engine routes from the
  `goal:g7.31.3` table — `write`, `read`, `send`, `dispatch|workflow`,
  `rotate|spawn` — and a regression test pinning those route tokens goes RED
  when any single name is removed from that line.

**What proves it.** Grep/read of the three surfaces shows one `routes:` line per
  file carrying every route token, AND the pinned test passes on the live bytes
  while a mutated copy (one token deleted from the routes line) fails.

**What disproves it.** A surface with no line naming all five, or a test that
  stays green after a route name is deleted (a vacuous checker).
