# hypothesis:a00-1ea8c652-91eca1

## Hypothesis

A decisive verdict's `evidence_runs` LIST must name the experiment that
produced the measurement the verdict's body claims. When the body quotes a tip
and a test tail, the node that actually ran them is the evidence; if the list
names only an experiment pinning an OLDER tip, the claim is reachable through a
node the verdict does not cite — a provenance defect that no gate catches,
because the cited entries still resolve.

**Proved if:** appending the measuring experiment to
`verdict:g7.27-harness-templates-falsifiers-hold`'s `evidence_runs` via
`write.py` yields raw frontmatter that reparses as a YAML LIST of three ids,
every id resolves in the corpus, and `evidence_gate.py enforce --dry-run`
still prints `0 unevidenced decisive verdict(s), 0 would demote, 0 refused`.
The gate is shown blind to the defect by handing it the PRE-fix two-id list: it
counts 2 and passes.

**Disproved if:** the appended list does not reparse as a list, any cited id
fails to resolve, or the gate demotes the verdict afterwards — in which case
the repair introduced a real evidence failure rather than fixing provenance.

**Not measured here:** the falsifier content itself, whose `d48eb062a` /
`70 passed in 1.31s` re-measurement belongs to
`experiment:dh-15-close-g7-27-evidence-gate-residue`. This round only makes the
verdict cite its measurer and corrects a prose mis-attribution on
`hypothesis:a00-7f6f1f95-b253cb`.
