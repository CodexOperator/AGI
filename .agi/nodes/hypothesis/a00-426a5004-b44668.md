## Hypothesis

**Absent `--persistent`, the non-persistent kid/parent spawn path in
`extensions/agi/bin/dispatch.py` is UNCHANGED by `goal:g7.28.1`** — the
rendered `spawn_args`/spawn env are byte-equal to the pre-persistent merge
base, exactly ONE child is launched, `_supervise_persistent` is never called,
the inline reaper is still armed (config `agent_dispatch.inline_reaper` default
`True`), and no `persistent` / `restart_count` keys reach the agent record —
for BOTH `--tier kid` and `--tier parent`. This is the falsifier for
`goal:g7.28.2` (multi-head split ≤2): persistent mode must remain opt-in and
not move the default path.

Proved by: dry-run command+env equality against the base module, plus a
real-Popen lifecycle count. Disproved by: any divergence in either, or by the
`--persistent` control failing to separate the two paths (which would make the
instrument vacuous).
