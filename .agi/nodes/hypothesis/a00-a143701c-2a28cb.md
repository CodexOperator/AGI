# hypothesis:a00-a143701c-2a28cb

## Hypothesis

A single `route(from_harness, to_harness)` decision can gate delivery: equal,
non-empty names select the native transport, while different or empty names
select the cross-harness `send.py` transport. `deliver()` must call exactly
one transport and pass that decision to it; neither transport may re-derive
routing from the harness pair.

## Falsifier and implementation

The claim is falsified if either transport can be selected independently of
`route()`, if `deliver()` invokes both, or if a transport can change the
route. The minimal seam is now in `extensions/agi/bin/send.py`: `route()` is
the sole comparison and `deliver()` selects one injected transport from its
return value. The focused same/cross/empty tests are in
`extensions/agi/tests/test_deliver_route.py`.

The tests were authored but not executed in this round because the task
permits only the completion CLI as a shell command; therefore this remains a
pending measurement rather than a proved claim.
