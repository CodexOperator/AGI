# hypothesis:a00-e5ef202a-0326f9

## Hypothesis

`extensions/agi/bin/ingest_session.py` can make its idempotence key **truly
injective** — and therefore hold the goal's "no silent drop" invariant over
arbitrary session ids — by making the non-UUID branch a **reversible encoding**
of the raw id (`canon` prefix + `hex` of the raw UTF-8 bytes) instead of a
truncated hash, and by **refusing by name** (`slug-too-long`, exit 2) any id
whose slug would exceed the filesystem limit rather than truncating it.

This continues `hypothesis:a00-a317e857-9dba03`, demoted to
`inconclusive_lean_disproved:60`: its fix appended `sha256(raw_id)[:8]`, a
32-bit birthday bound, and the parent measured a pair of distinct ids sharing
that suffix — the second printed `INGEST skip` and was dropped.

**Testable claim.** For any two distinct session ids `a != b`, `slug_for(a) !=
slug_for(b)`; concretely, the parent's crafted collision pair mints TWO node
files each carrying its own raw `source_session`, never one node for two
sessions. A canonical UUID keeps its BARE slug and stays idempotent (including
an upper-cased spelling). An id whose slug would exceed 200 chars exits 2 with
a named `slug-too-long` reason and mints nothing.

**Proved by:** `experiment:a00-e5ef202a-ingest-reversible`'s raw transcript
(crafted pair -> two files; probe pair -> two ids; real UUID fresh+re-ingest;
three named refusals; the 200/202 boundary) and `test_ingest_session.py`
9/9.

**Disproved by:** the second of any colliding pair printing `INGEST skip` or
one node file serving two sessions; or an over-long id being truncated (a
truncated reversible suffix is no longer reversible — the collision would
return) or raising an unhandled OSError.

## Mechanism

`slug_for` has two disjoint branches. A canonical UUID (case-insensitive) maps
to the bare `grok-session-<uuid>`, preserving the one live corpus node and its
idempotence. Every other id maps to `grok-session-<canon>-<hex(bytes)>`; `hex`
is a bijection on byte strings, so distinct raw ids give distinct tails by
construction, independent of any collision probability. The `canon` prefix is
cosmetic; the fixed-length tail alone determines the raw id, so it cannot
rescue a collision. A 200-char guard refuses by name rather than truncating,
and `write_node(..., on_exists=SKIP)` remains the idempotence mechanism.
