# hypothesis:a00-5ffe6174-59e3aa

## Hypothesis

A whole-graph sweep that walks every node declaring `profile_ref` (live and
retired), projects each body, compares bytes to the artifact on disk, and is
wired as a pre-rotation guard in `rotate.py`, will refuse rotation with a
non-zero exit and a named node on a deliberate desync, while a rotation with
nothing drifted stays a clean no-op.

**Proved if:** a scratch graph whose linked artifact is mutated (or deleted)
makes `profile_sync.py --all` exit 1 naming the node, and the rotate guard
returns a named refusal at a call site that runs before any side effect;
a clean graph exits 0 and the guard returns None.

**Disproved if:** the sweep cannot see retired (`nodes/deprecated/`) nodes,
misses a missing/refused ref, or the guard's call site sits after a rotation
side effect — or a clean rotation is blocked.

Built and proved in `experiment:whole-graph-drift-sweep-pre-rotation-guard`
(probes: gate/wire/auth all green). Production bytes: `profile_sync.py`
(`check_all` + `--all`) and `rotate.py` (`_check_profile_drift` wired into
`cmd_rotate_self`).
