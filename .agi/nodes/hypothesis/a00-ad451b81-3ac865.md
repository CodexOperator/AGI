# hypothesis:a00-ad451b81-3ac865

## Hypothesis

`tmux_hold.py` can be made a first-class, versioned adapter without making tmux mandatory: when the named tmux server/session is unavailable, the same `restart` seam should fall back to direct `Popen`, while the normal path still holds and reattaches one stable pane per seat.

## Testable claim

A probe covering both environments (tmux available, and tmux/session unavailable) will show that the adapter preserves the stable named-pane restart behavior when tmux is present and still returns a runnable child through `Popen` when it is not. Grid coverage will identify the adapter's source file or build payload on tip.

## Falsifiers

- The source has no build node/payload or grid coverage entry after the change.
- The no-tmux/no-session path raises instead of using `Popen`.
- The fallback bypasses the adapter seam, or first spawn still uses anonymous `Popen` while hold is enabled.
