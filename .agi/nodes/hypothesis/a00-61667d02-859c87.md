## Hypothesis

A whole-graph profile sweep (and the rotate guard that wraps it) can be made
to survive an unparseable node file without weakening its core falsifier:
an unparseable file that carries **no** `profile_ref:` hint is not a
profile-linked node and must be skipped, so an in-sync graph with a malformed
unlinked sibling stays a clean no-op (exit 0, guard None); an unparseable file
whose raw bytes **do** carry `profile_ref:` cannot be proven in sync and must
be surfaced as a named `unreadable` failure carrying its path, so `--all`
exits non-zero.

**Proved by:** `check_all` guarding its `load_node_file` call, plus the
`--all`/guard probes in `experiment:malformed-sibling-clean-noop`.
**Disproved by:** any malformed unlinked sibling that still makes the sweep or
the guard refuse, or any malformed linked file that is silently dropped.
