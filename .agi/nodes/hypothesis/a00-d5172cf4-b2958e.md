# hypothesis:a00-d5172cf4-b2958e

## Hypothesis

The caller-facing **READ** surface is transport-invariant, exactly as the
SEND surface (`send_dm`) and the NUDGE surface (`_nudge_target` /
`_nudge_window`) were measured to be in DH.21–DH.51. The read surface is
`read`, `peek`, `read_dm`, `peek_dm`, `read_dms`, `read_room`, `peek_room`.

Three conjuncts, each with a negative probe (below, one test each):

1. **gate** — no read-shaped signature accepts a transport, box, or `ssh`
   parameter; handing the surface the exact foreign-box state does not change
   the call or its result. The read API is blind to the peer's box.
2. **wire** — no read-shaped body branches on a transport predicate. An AST
   scan of the seven function bodies finds zero `is_ssh` / `row_is_local` /
   `ssh` tokens, and a live call still reaches the real bytes on disk.
3. **auth** — passing `is_ssh=...` to any read-shaped function is refused by
   name (`TypeError: got an unexpected keyword argument 'is_ssh'`), not
   silently ignored and not a second transport-specific API.

**The only `row_is_local` uses in read-shaped callers are explicitly-local
service readers**, not the shared surface: `mail_poll` (CLI flag
`--box-local`, `send.py:5431`) and `wake_all_local` (`send.py:2816`, name says
local). `_nudge_target` (`send.py:2178`) is a sender-side refusal, not a
reader; `_whois_answer` (`send.py:4487`) is a display guard. No production
byte carries `is_ssh` on the correct paths.

## What would prove it

A foreign-box row present in the graph, and `read(root, "far-seat", ...)`
returning the same shape/result as `read(root, "local-seat", ...)`; an AST
scan of the seven bodies with zero transport tokens; `read_dm` with a real dm
on disk returning the transcript; and every read function raising `TypeError`
on `is_ssh=...`.

## What would disprove it

Any read-shaped signature gaining a transport/box/ssh parameter; any read body
referencing `is_ssh`, `row_is_local`, or `ssh`; or an `is_ssh` kwarg being
accepted (or quietly absorbed by `**kwargs`) instead of refused.

This is the **READ third** of the invariant that DH.21/DH.25/DH.31/DH.37/
DH.43/DH.51 pinned only for SEND and NUDGE. It has no committed test and no
prior probe.
