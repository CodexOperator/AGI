# hypothesis:a00-0263e9f7-7b89ff

## Hypothesis

A **production** CLI at `extensions/agi/bin/ingest_session.py` turns a fixture
grok session artifact (JSON: `{harness, session_id, path, summary}`) into a
node under `<graph-root>/nodes/`, and satisfies the whole of `goal:g7.32.1`'s
falsifier + invariants, not just the idempotence mechanism kid #1 probed:

1. Given the fixture it prints ≥1 new graph node id on stdout and writes a
   node file, parented to `goal:g7.32.1`, via `node_writer.write_node`.
2. Re-ingest of the same artifact returns the SAME node id and mints no second
   file (the `ingest_key = sha256(f"{harness}:{session_id}")[:16]` scan).
3. A malformed artifact (missing `harness` or `session_id`, or unreadable JSON)
   is **refused by name** on stderr with a non-zero exit — no traceback, no file.
4. The minted node carries `edited_by` and `thought_session` from CLI flags.

**Would prove it:** `python3 -m pytest extensions/agi/tests/test_ingest_session.py -q`
passes on a throwaway `--root`, exercising (1)-(4).

**Would disprove it:** any assertion fails; or the CLI returns a different id
on re-run; or a malformed artifact raises instead of refusing.

## Boundary

The artifact is synthetic — there is no Grok transcript on this box, so this
proves the *pipe*, not Grok field mapping. The key is `(harness, session_id)`
only, so content is frozen at first ingest; an update/supersession path is out
of scope and is the obvious child.

The production file is 65 lines against a 40-line ceiling (argparse plus the
named-refusal path); under the 2× stop threshold, recorded honestly.
