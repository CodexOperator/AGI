# hypothesis:a00-2b1e2b82-739979

## Hypothesis

**A `write.py` edit whose node declares a `profile_ref` that will be
refused is ALL-OR-NOTHING.** Either the node body does NOT advance and
`write.py` exits non-zero naming the refusal, or the node write is recorded
as landed with a named repair. A bare rc=2 with an advanced node body and a
stale artifact — today's outcome — must no longer occur.

This is residue (b) named by `experiment:a00-1b9a8e7e-profile-sync`, the
"no drift created by the driftless route" half of `goal:g7.31.5.1`'s
invariant: a refused ref today leaves graph and projection disagreeing.

## What would prove it

On the real built engine, in a scratch repo: a body edit to a node whose
`profile_ref` (a) escapes the repo root, (b) resolves under `.agi/nodes/`, or
(c) names a directory exits non-zero, names the refusal, and leaves the node
body byte-identical to before — with no refusal artifact written. Plus a
regression: the happy path still projects in the same action, `--check` still
reports DRIFT without writing, a node with no `profile_ref` is a silent
no-op, and residue 4 holds (a failed payload does not advance the
projection).

## What would disprove it

Any refused ref that still advances the node body, or a refusal that lands
without naming its reason, or the happy path / `--check` / no-ref behaviour
regressing.

before `node_writer.update_node`; all four refusal-class probes pass and the
regression cases hold. See `experiment:a00-2b1e2b82-preflight-refusal`.
