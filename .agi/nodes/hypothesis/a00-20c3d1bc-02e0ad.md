# hypothesis:a00-20c3d1bc-02e0ad

## Hypothesis

The held restart path should compute exactly one environment through the adapter's `child_env(harness=..., base=scrubbed_env(), tier=...)` seam before any held-pane return, and pass that same mapping into every tmux operation that can create or replace the pane process. Merely reattaching to a live pane must not recompute or mutate its environment.

The `tmux_hold` boundary should accept an optional `env` mapping and translate only its string entries into explicit tmux `-e KEY=value` arguments for `new-session` and `respawn-pane`; shell command construction must not be the carrier. When tmux lacks `-e` support or the session is unavailable, the existing direct-`Popen` fallback should receive the exact same mapping. Values, including empty strings, should be preserved; values containing NUL should fail before tmux is invoked.

## Proof

A focused adapter test should stub tmux and prove all of the following for a `credential: none` row whose inherited environment contains `OPENROUTER_API_KEY` plus a harness-only key:

1. default held restart calls `child_env` before returning the held pid;
2. both the environment returned to the restarted process and the tmux arguments omit `OPENROUTER_API_KEY`;
3. the harness-only key is present in both places;
4. the default unmarked row retains `OPENROUTER_API_KEY`;
5. reattach-only calls pass no creation/respawn arguments and preserve the live pane environment;
6. direct-`Popen` fallback receives the identical scrubbed environment.

A second test can pin command compatibility by recording `_cmd` arguments without invoking a live tmux server. The implementation passes only when no held creation/respawn path can silently fall back to tmux-server inheritance.

## Falsifier

Disprove the claim if any held path can return a pid without reaching `child_env`, if a newly created or respawned pane receives raw inherited credentials, if harness-specific environment is absent from the pane, or if the fallback environment can differ from the held environment.
