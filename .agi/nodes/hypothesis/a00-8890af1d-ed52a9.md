## Hypothesis

The single transport resolver behind `send`/`wake` (`goal:g7.31.4`) can be made
to hold ONE address policy across local and mesh without leaking a transport
branch to any caller: a foreign pane is addressable only through a live-looking
`@id` (a NAME or absent `window` cell is refused exactly as the local path
refuses it), the town's `location` is validated as a bare host name before it
becomes ssh argv, a foreign seat with no transport reports the truth rather
than a false `typed-token`, and a stored deferred dm rides the mesh inline.

**Proved when:** four committed tests in
`extensions/agi/tests/test_send_mesh_transport.py` pass on the built bytes —
(1) a foreign mesh row with a NAME/absent window yields no ssh argv and no
typed token; (2) a leading-dash `location` yields no ssh argv while a valid one
still yields `['ssh', <alias>]`; (3) `wake` on a foreign no-mesh row returns
False, names `mail_poll`, and prints no `typed-token`; (4) a stored deferred dm
is typed inline through ssh and cleared after delivery.

**Disproved when:** any of the four fails, or a `foreign`/`is_ssh` branch
appears at a `send`/`wake` call site, or `_nudge_target`'s local refusal changes.

The four loci were recorded as failing on the OLD bytes in
`hypothesis:a00-330fa322-a3a814`. This node's experiment is
`experiment:mesh-transport-corrective`; its verdict holds exactly the four
tests above as evidence.
