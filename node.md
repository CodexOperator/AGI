for pre-stamp nodes and is documented as the weaker path.

`post_wire.cmd_wire` called it inside its agent loop, a node with malformed
frontmatter would have taken down a whole iteration's wiring instead of
skipping one node. A predicate has exactly one safe answer for input it cannot
read, and that choice is local — it is not a vote on the unified reader's
default, which `goal:g13`'s chain is deciding.
