# idea:tree-context-forked-conversations-searched-by-a-swarm

## The idea
Context that grows like a tree, the way the owner describes a human mind doing it: a conversation FORKS at a decision point (pi's chat fork, Claude Code's --fork-session), the branches run side by side, and a swarm searches ACROSS several conversations at once, like a continuous binary tree search. The graph already holds nodes as thoughts; this makes a conversation branch a first-class, searchable node too.
