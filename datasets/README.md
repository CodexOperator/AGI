# datasets/ — the town's synthetic, preclassified research corpus

**Why this directory exists (owner, 2026-09-20 21:5xZ, verbatim on `goal:g14`):** "Put all synthetic datasets into a separate easy to find easy to browse archive with its own explainer doc that you also build into the graph." Every dataset the town's evals and rounds generate lands here, at the repo root (the same reason `GOALS.md` lives at the root: the things a human opens first are not hidden in a dot directory). The graph node for this explainer is **`doc:lm-research-corpus-registry`** (`.agi/nodes/doc/`), whose payload is this file — edit the file, the node follows.

Every record here was **generated by a model and labelled by a measurement** (an execution result, a verdict, a byte-identity check, a reviewer's residue). That is what "preclassified" means: the label came for free from the experiment that produced the record, so the corpus can be used for tune-ups (SFT/LoRA, calibration, reward modelling) without a labelling pass.

## What is NOT here yet, and the rule that fixes it

- **Parent/kid trajectories before ABC.01** were removed with their worktrees; 344 of 354 kid-SFT examples lack one for exactly this reason. From ABC.01 on they land under `trajectories/` (rule 2 below). `kid-sft/` was scrubbed by the older token-then-replace scrub, which can corrupt an unrelated hex run sharing a short prefix (found 2026-09-20); it is re-scrubbed with the span tool (DS.01) before it is used as a training input.
- **A paid reference row** (deepseek-v4.1-flash on the same evals) does not exist for any eval yet; the owner's switch rule ("within 10% of deepseek v4.1 flash") needs it.

**Landing rule (thought-master, standing from ABC.02 on):**
1. Every eval round commits its `(prompt, output, label)` triples as one jsonl under `datasets/<round-id>/` with a `README.md` naming the eval, model/arm, template, scorer and label semantics. Artefacts that must stay beside their harness are symlinked here, never duplicated.
2. **Before a worktree is removed, the director lands the round's parent and kid trajectories** into `datasets/trajectories/<round-id>/`, run through the kid-SFT scrub (`kid-sft/build_corpus.py`: hex keys, IPs, OpenRouter ids, emails) and labelled with the verdict + mur recommendation. Engine-level retention is an SM queue item; until it lands this is a hand step checked at merge.
3. A harvested workflow run's stage JSON is committed under `datasets/workflow-runs/<name-date>/`.
4. This index is updated in place at every merge that adds a corpus.

## How to load

```python
import json, glob
kid  = [json.loads(l) for l in open('datasets/kid-sft/kid_sft.jsonl')]
acts = [json.loads(l) for l in open('datasets/jev-typed-acts/acts_replay_scrub.jsonl')]
he   = {arm: [json.loads(l) for l in open(p)] for arm, p in
        [(p.split('/')[-1].split('_')[0], p) for p in glob.glob('datasets/humaneval-abc/arm*.completions.jsonl')]}
```
Nothing here needs numpy; every file is jsonl, json, md or txt. Model bytes never live here (`/data/ml/models` on the rig only).
