## Protocol actually run

**HumanEval.** `datasets/humaneval-abc/runner.py` was run **byte-identical**:

```
ABC_OUTDIR=datasets/switch-rule/2026-09-21 \
  <scratch>/venv/bin/python datasets/humaneval-abc/runner.py \
    ref_deepseek-v4.1-flash http://127.0.0.1:8787 deepseek/deepseek-v4.1-flash \
    datasets/switch-rule/2026-09-21
```

The runner hard-codes the same one-fixed-template request and posts to
`BASE + "/v1/chat/completions"`. It cannot carry the OpenRouter key and it sends
llama.cpp's `chat_template_kwargs`. Both gaps were closed **outside** the runner
by `proxy.py`, a local forwarding HTTP shim that:

1. injects `Authorization: Bearer $OPENROUTER_API_KEY`,
2. forwards to `https://openrouter.ai/api/v1/chat/completions` (so the runner's
   base is `http://127.0.0.1:8787` and its `/v1/chat/completions` path is kept),
3. drops `chat_template_kwargs` and adds `reasoning: {"enabled": false}` — the
   OpenRouter equivalent of the local arms' `enable_thinking: false`,
4. logs each response's `usage` to `usage_log.jsonl`.

**Why the shim and not a one-line edit to `runner.py`:** the parent asked for
`runner.py` to stay byte-identical if possible, and it is — verified by reading
the file back. The request body that reaches the model is the local body with
exactly the two documented protocol translations, so the reference row is the
same protocol as A/A2/B/C1/C2.

**Scoring.** `datasets/humaneval-abc/scorer.py` was also run UNCHANGED:

```
ABC_OUTDIR=datasets/switch-rule/2026-09-21 <scratch>/venv/bin/python \
  datasets/humaneval-abc/scorer.py ref_deepseek-v4.1-flash \
  armA_qwen3.5-9b-q4km armA2_qwen3.5-9b-q4km-fork armB_bonsai27b-ptq1 \
  armC1_bonsai27b-abliterate-s1 armC2_bonsai27b-abliterate-s2
```

Tags are the full file stems (`<tag>.completions.jsonl`), so `A`/`B`/`C1` in
`scores.json` correspond here to `armA_…`, `armB_…`, `armC1_…`. The five local
per-problem pass/fail maps are recomputed by the same scorer in the same run, so
the discordant `b`/`c` counts and exact McNemar p in `gap_table.md` are real
per-problem pairings, not estimates.

**IFEval.** Install path: **fresh scratch venv** (`python3 -m venv` under the
session dir) + `pip install absl-py langdetect nltk immutabledict`, and the
official sources fetched raw from
`github.com/google-research/google-research/instruction_following_eval/`
(`evaluation_main.py` + `instruction_following_eval/{__init__,evaluation_lib,
instructions,instructions_util,instructions_registry}.py`). Chosen over cloning
the whole repo because only the eval package is needed and the fetch is
reproducible. `nltk punkt_tab` data was downloaded into `~/nltk_data`.

Responses were generated by `ifeval_gen.py` through the same `proxy.py` shim
(one `reasoning.enabled=false`, temperature-0 sample per prompt). Because the run
is long, four shard workers were used with disjoint indices
(`ifeval_gen.py <input> <base> <shard> <nshards>`), each writing its own
`.shard<k>` file; the shards were merged back into official prompt order to make
the final file. Run:

```
cd <scratch>/ifeval && <scratch>/ifeval_venv/bin/python evaluation_main.py \
  --input_data=<scratch>/input_data.jsonl \
  --input_response_data=datasets/switch-rule/2026-09-21/ref_ifeval_deepseek-v4.1-flash.responses.jsonl \
  --output_dir=datasets/switch-rule/2026-09-21
```

Result (official `print_report`): **strict prompt-level accuracy 0.868762
(470/541)**, loose 0.894640, strict instruction-level 0.908873.

## Deviations from the local-arm protocol (recorded, not hidden)

1. **Thinking-off expression differs in spelling, not intent.** Local arms:
   `chat_template_kwargs {"enable_thinking": false}` (llama.cpp). Reference:
   `reasoning {"enabled": false}` (OpenRouter). The local knob is not accepted by
   OpenRouter; this is the documented equivalent. A one-call probe returned a
   non-empty completion with `reasoning_tokens: 0`.
2. **Serving stack differs by construction** — OpenRouter (provider DeepInfra)
   vs the local llama.cpp fork. This is inherent to an API reference row.
3. **`chat_template_kwargs` dropped by the shim.** No other request field was
   changed: `temperature 0.0`, `top_p 1.0`, `top_k 1`, `seed 1234`,
   `max_tokens 512` for HumanEval and `1280` for IFEval are forwarded as sent.
4. **Per-row usage/cost is not in `raw.jsonl`.** `runner.py` does not record it
   and the shared proxy log has no `task_id`, so attribution would need a second
   paid pass. Aggregate tokens/cost are in `usage_totals.json`.
5. **IFEval used max_tokens 1280** (a generation budget the official harness does
   not itself prescribe); HumanEval stayed at the local arms' 512.

## Cost

714 paid calls, 55,381 prompt + 233,972 completion tokens, **$0.19277 total**
(summed from `usage_log.jsonl`), against the $1.00 cap for both evals. Part of
the run fell in the 01–04Z weekday 2× surcharge window and did not approach the
cap. The extra 9 calls above 705 are the protocol probe and a cancelled
single-worker IFEval pass that was re-run under four shards (its rows are also
counted; the merged final file has exactly 541 unique prompts).
