## World Generation & Layout

Covers dungeon-generation and town-scene. Implement procedural algorithms for dungeon layouts, room generation, spatial connectivity, and town layout. Design level templates, room connectivity rules, and transitions between areas. Includes environmental asset placement respecting the Three.js scene constraints (MeshBasicMaterial, no lights).

## Player Character & Inventory System

Covers inventory mechanics. Implement item collection, equipment slots, inventory UI, and item attributes. Track inventory capacity, equippable items, stat modifications from equipment, and item interactions. Define item types, rarities, and stat bonuses.

## Combat & Enemy AI

Covers damage-logic and enemy-ai. Implement damage calculation mechanics, hit/miss resolution, enemy behavior patterns (patrol, chase, attack), combat encounters, and NPC interaction during fights. Define enemy types, stat ranges, and aggression conditions.

## Quest & Progression System

Covers quests. Implement quest objectives, quest tracking UI, progression gates, quest rewards, and narrative progression through the dungeon. Define quest chains, completion conditions, and failure states.

## Save & Load System

Covers save-load. Implement game state serialization, checkpoint management, load-game functionality, and state recovery between sessions. Define what state is persistent (player position, inventory, quest progress, enemy state).

## Multiplayer Networking

Covers multiplayer-net. Implement network synchronization, co-op player coordination, communication protocols, and shared world state management. Design player discovery, session creation, and real-time state sharing.
