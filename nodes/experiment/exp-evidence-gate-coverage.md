The `cli.py`/`post_wire.py` gate is real, correctly implemented, and tested (384 tests per `exp:evidence-gate-resolution-r1`). But `SKILL.md`'s own runtime table (line 56-61) puts `cli.py done`, `dispatch.py`, `heal.py` all under "pi harness" — and separately confirms `post_wire.py` is only invoked from `driver.sh` step 7, which is pi-harness-only (I read `driver.sh` in full: it calls `snapshot-goals.py`, `snapshot-build-site.py`, `render-context.py`, `metrics.py`, `benchmark.py`, `dispatch.py`, `heal.py`, `post_wire.py`, `cli.py status` — never `grid.py`). CC-native dispatch — the runtime that spawned this exact session — never calls either gated writer path. Its only enforcement is prose: SKILL.md step 4 tells the parent to demote unevidenced verdicts "by hand," and step 5's actual scripted action is a plain `git commit` followed by `grid.py commit --all`, neither of which imports `evidence_gate`.

**Can it recur:** Yes, precisely. Two ungated paths exist in the currently-active protocol (not retired code): (1) a kid's direct node-file write, and (2) the parent's `git commit` + `grid.py commit --all` that immediately follows it. Both are documented, sanctioned steps of CC-native dispatch (`agi/skills/agi/SKILL.md:56-90`), not accidents. `grid.py commit --all` is also the target of the 5-minute cron snapshot (`CLAUDE.md` "Two-cadence cron"), so within 5 minutes any hand-written `verdict: proved` with no `evidence_runs` is durably versioned regardless of what the parent's manual review caught or missed. The mechanism that produced the 104 — an unreviewed writer with no code backstop — is structurally still present; it just moved from ad hoc Python scripts to the parent LLM's own diligence during CC-native review. `unevidenced_decisive_verdicts` would only catch a recurrence after the fact, on the next `metrics.py`/`dashboard.py` run, exactly as it caught this one.

**Proposed fix:** `extensions/agi/bin/grid.py`, function `cmd_commit` (lines 173-198). This is the one choke point every write path already passes through unconditionally — pi-harness and CC-native both funnel into it (`SKILL.md:47,87,168`), and cron guarantees it runs within 5 minutes even if a parent skips it manually. Before `commit_file(root, p, ref, msg_prefix)` at line 194: import `evidence_gate` (same pattern as `cli.py:20-22`/`post_wire.py:27-28`), build `corpus = evidence_gate.build_corpus(root / "nodes")` once at the top of `cmd_commit` (mirrors `post_wire.py:137`), and for each `p` about to be versioned, read its frontmatter (grid.py has no YAML-frontmatter reader yet — add one, or factor the three near-duplicate copies already in `cli.py`/`post_wire.py`/`evidence_gate.py` into one shared helper while here). If `fm.get("verdict")` is decisive (`evidence_gate.requires_evidence(...)`), call `evidence_gate.apply_gate(verdict, fm.get("evidence_runs"), corpus=corpus)`; on a non-clean result, rewrite the file via `evidence_gate.stamp(fm, gate)` *before* calling `commit_file`, so the version grid.py records is already the demoted/honest one, never the overclaim — matching the project's existing "demote, do not discard" ethic (`idea:engine-evidence-gate`) and `post_wire.py`'s per-file-skip-not-whole-run precedent (don't abort `--all` over one bad file; a hard exit would also break the 5-minute crash-recovery cadence this same command serves via cron). Print a summary count of any auto-demotions at the end of `cmd_commit`, matching `post_wire.py:288-295`'s `demoted`/`rejected` report. This closes the hole without touching the CC-native kid/parent contract at all — kids keep writing freely, the parent keeps reviewing by hand, but nothing reaches a durable grid version, cron-pushed or not, without passing through the same `evidence_gate.apply_gate` call the pi-harness path already trusts.

**Deliberately not proposed:** gating at the kid's Write-tool call, or making `SKILL.md` instruct the parent to call `cli.py done`/`post_wire.py` per kid. Both require either engine changes I can't make from a prompt file, or trusting prose discipline again — the same class of control that let this go undetected for over three months the first time.
